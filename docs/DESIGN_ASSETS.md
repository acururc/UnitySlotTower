# デザイン素材の一覧

2026-11-19 時点の仕様（spec D-01〜D-100）で必要な素材。11/7 の依頼書の内容はこの一覧で置き換える。見た目・世界観・色はデザイナーの自由で、ここにはゲームの都合と技術の条件だけを書く。

## デザイナーが作るもの

### 味方（4種）のモデルとモーション
- タンク: 地上に置く。敵を3体止める。硬い
- 剣士（近距離）: 地上に置く。敵を2体止める
- 弓（遠距離）: 高台に置く。空中の敵を攻撃できる唯一の味方。単体攻撃
- バッファー: 高台に置く。範囲内の味方の攻撃力を上げる（攻撃はしない）
- 4種は形と色の大まかな違いで、上から小さく見ても見分けられること
- モデルを共通にして武器や装備で4種を分けてもよい（作り方は自由）
- モーション: 待機・攻撃（バッファーは強化の動き）・死亡は必須。置いたときの登場と被弾はできたら
- 味方は歩かないので、移動モーションはいらない

### 敵（4種＋ボス2種）のモデルとモーション
- 近距離: 地上を歩く。止められると、止めた味方を殴る
- 遠距離: 地上を歩きながら離れた味方を撃つ（高台の味方も狙う）
- 空中: 高さ 約1.2m を飛ぶ。止められない。飛んでいると分かる形
- 重装: 地上を歩く硬い敵。遠距離の攻撃が効きにくい（盾などで硬さが分かるとよい）。味方の止める枠を2つ使う大きめの敵
- 中ボス・最終ボス（できたら）: ほかの敵の拡大・差分でもよい。最終ボスは周りを一度に攻撃する。間に合わなければ企画側が拡大と色替えで代わりにする
- モーション: 移動（空中は飛行のループ）・攻撃・死亡は必須。待機と被弾はできたら。最終ボスの範囲攻撃はできたら

### リールの図柄（6種）
- 赤7・青7・緑7・黄7・BAR・コイン
- 7の4色は、それぞれ1種の味方のスキルに結びついている（仮: 赤=剣士、青=弓、緑=バッファー、黄=タンク。組み合わせはデザイナーが決めてよい）。色と味方の対応が分かると、なおよい
- 4色の7は、色だけでなく形や模様でも見分けられること（色が見分けにくい人のため）
- コインの絵は、画面のコイン表示と同じものを使う
- 7・BAR はスロットらしくてよいが、実在の機種のまねはしない
- 3つの図柄が横に並んで表示される（1リールの幅は 約330px）

### スロット筐体
- 画面の下半分の下側、1440×720 px
- 部品を別々の画像にする: 枠、リール窓（約 1016×500）、レバー（倒した状態も）、コインの絵（飾りを足すのは自由）
- 停止ボタンはいらない（リールは自動で止まる。レバーだけ）
- 文字は入れない

## 技術の条件

書き出し設定・フォルダ・ファイル名の詳細は [`DESIGN_SUBMISSION.md`](DESIGN_SUBMISSION.md)。

- 3D: FBX＋テクスチャ（PNG）。モーションも FBX。元データ（.ma / .mb / .blend など）も一緒に
- 1単位＝1m。1マスは 1m×1m。キャラは高さ・幅 0.8m 以内（重装は少し大きくてよい）
- 原点は足元の中心（空中の敵は体の下の中心）。正面が +Z
- 人型は Unity の Humanoid で使える骨組み。四足など人型でないものは骨組み自由。武器は手の骨の子
- ポリゴン数の目安: キャラ 3,000〜5,000 三角形、ボス 8,000 まで
- テクスチャ: キャラ 1024×1024 を1枚。マテリアルはキャラ1体につき1つ（武器込みで2つまで）。法線マップ・光沢マップはいらない
- モーション: 攻撃は1秒以内が目安で、超えてもよい（ゲーム側で再生速度を合わせる。当たる瞬間のフレーム番号を教えてほしい）、ループは最初と最後のポーズを同じに、30fps
- 2D: 透過PNG（sRGB）。図柄は 512×512（外側 32px は余白）、筐体は上のサイズ
- ファイル名は半角の英小文字・数字・`_` だけ（例: `chr_ally_tank.fbx`、`anim_enemy_heavy_walk.fbx`、`icon_reel_red7.png`、`cabinet_lever.png`）
- 既存の素材を使ったときは、名前・URL・ライセンスを `credits.txt` に書いて一緒に納品

## 企画側が用意するもの（AI で作る・サイトから持ってくる）

文字を使わない UI なので、意味は絵・色・形で伝える。全画面で線の太さと色調をそろえる。

### 全画面で共通
- 背景（画面ごと、または共通の1枚）
- パネル・札・ボタンの地と縁（今は角を切った形 `UiPanel`）
- 共通の記号: 決定 ▶、戻る ◀、閉じる ×、押せないときの印
- お金の絵: コイン（図柄と共通）、所持金
- ライフ、スキルのゲージ（4色）
- 日本語フォント: Noto Sans JP（選定済み）

### タイトル
- タイトルロゴ（画面で唯一の文字）
- 開始 ▶ ボタン
- 難易度（設定1〜6）の選択の札（数字は使える）

### ルート選択（3列・8階）
- マスの種類のアイコン: 戦闘・強敵・ショップ・回復・ボス
- マスの台と状態: 今いるマス、行けるマス、通ったマスの印、行けないマス
- マスをつなぐ線（行ける道・通った道・それ以外）
- 今の位置の印（駒）と、移動のアニメ
- 行き先の矢印（筐体の各リールの真上に出る）
- 地図の背景（下から上へ階が積み上がる）

### ショップ
- 品の札: 味方のストック（4種）、スキルゲージ（4色）、強化。職ごとの見分け
- 値段の表示（所持金の絵＋数字）
- 両替（所持金→コイン、コイン→所持金）の絵と矢印
- 買えない・足りないときの暗い状態
- 店らしさが分かる背景や看板（文字なし）

### 回復
- 回復を表す絵（回復した量とライフを見せる）
- 休む場所らしい背景

### 戦闘
- ステージ: 地上・高台・通行不可のタイル、出口・本拠地、マップの外側の飾り
- 上端の帯: 残りの敵、倍速（×1〜×3）、一時停止、強化中の倍率
- 味方の札の絵（味方のモデルから作る）、無料ストックの印、待ち時間の表示
- 選んだ味方の詳細の板: 強化、撤退
- ブロック数（壁と三角、0 は ×）、向き選びの矢印
- スキル4種の絵
- 戦闘開始・勝利の帯、出口の印、本拠地が攻撃されたときの光

### リザルト
- クリア（王冠）とゲームオーバーの絵
- 到達した階・所持金・コインの表示
- リトライ ▶・タイトルへ ◀

### 説明・早見表
- 操作を示す手（指先と、押した所に広がる輪）
- 説明の絵: マスの中身（戦闘・強敵・ショップ・回復・ボスで何が起きるか）、足止めの図
- 一時停止中の早見表: スロットの図柄と効果、味方ごとの性能と攻撃範囲の図、? ボタン

### エフェクト
- 攻撃が当たる、矢・弾、強化中、撃破、召喚、範囲攻撃、コインが落ちる、図柄が揃ったときの光、スキル発動

### 音
- BGM: タイトル、ルート選択、戦闘、ボス戦、ショップ・回復、クリア、ゲームオーバー
- 効果音: レバー、リール回転・停止、図柄が揃う（7・BAR・コイン）、ボタン、召喚・配置、攻撃・被弾・撃破、本拠地が攻撃される、スキル発動、購入・両替、回復、ルートの移動、勝利・敗北

入手元とライセンスは [`ASSET_LICENSES.md`](ASSET_LICENSES.md) に記録する。
