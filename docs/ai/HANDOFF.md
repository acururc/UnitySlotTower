- Unity 接続: 停止済み（8080 閉を確認、2026-11-15 T350b 後。Editor は開いたまま、Game シーンを開いている）。Editor の camera screenshot は半透明の UI（暗幕など）が薄く写る。濃さは画像で判断しない。テスト実行スクリプトは refresh 後の Console に `error CS` があれば止める（古いアセンブリのままテストが流れて全件成功に見えるため）。Editor は開いたまま。テスト実行は refresh → 25秒待つ → Console → tests --async → poll-test のループを1スクリプトにまとめる（結果は `progress.failures_so_far` と `result.summary`）。`editor refresh` は成功しても exit 1 を返す。

- CLI はテスト失敗・poll 中・`editor refresh` 成功時でも exit 1 を返すことがあるので `try {} catch {}` で包み、中身の JSON で判断する。
