# 音（spec 014）

状態: 承認済み
承認: 2026-11-27、FR-001〜FR-007 と AC-001〜AC-003 の検証方法（ユーザー「承認」）

## 目的

sakurai の評価 #6「音声ファイルが1つもない」への対応。スロットと戦闘の手ごたえを音で支える。

## 現状

- 音声ファイルも、音を鳴らすコードもない。`Runtime/Data/PresentationCatalog.cs` の `Entry.sound`（AudioClip）は使われていない。

## 確定した決定（ユーザー回答）

- D1 範囲: 効果音（スロット・戦闘・UI）＋BGM（タイトル・戦闘・ボス）＋音量設定（BGM と効果音）。（2026-11-27）
- D2 音量設定: BGM と効果音のスライダー2本（0〜100%）。タイトルと一時停止中に置き、文字なしでアイコン（音符・スピーカー）で区別する。値は保存して次回も使う。（2026-11-27）
- D3 素材: AI がログイン不要の無料素材（CC0 の効果音集、ゲームで使える BGM）から選んでそのまま使う。通しで聞いて気になる音だけ差し替える。差し替えは参照を付け替えるだけで済む作りにする。出典とライセンスは `docs/ASSET_LICENSES.md` に記録する。（2026-11-27）

## 要求

- FR-001 効果音（スロット）: 賭け（1枚ごと）、レバー、リール回転中（ループ）、リール停止（1本ごと）、ライン成立、ハズレ。効果の発動音は 赤7（ブレス）・青7（凍結）・緑7（回復）・黄7（毒）・BAR（強化）・コイン（コインが降る）で別々にする。ステージ1の見せ場の最初の揃いも同じ音を使う。
- FR-002 効果音（戦闘）: 味方の配置、味方の攻撃（剣・弓。盾と強化役は攻撃しないので鳴らさない）、敵への命中、敵の撃破、ボスの撃破、本拠地への被弾、ウェーブ開始、ボスの登場、勝利、敗北。
- FR-003 効果音（UI）: ボタンを押す音（共通）、置けないところに置こうとしたときやお金が足りないときの拒否音、コインの獲得。
- FR-004 BGM: タイトル、通常の戦闘（ステージ1〜7）、ボス戦（ステージ4の中ボスと8のボス）の3曲をループで流す。画面やステージが替わったら短くフェードして切り替え、同じ曲なら流し続ける。勝利と敗北のときは BGM を止めてジングル（FR-002）を鳴らす。
- FR-005 鳴り方: 同じ効果音が同時に鳴る数に上限を設ける（攻撃・命中・撃破が重なって割れたりうるさくなったりしないように）。一時停止中は効果音を止め、BGM は流し続ける。倍速でも音の高さは変えない。
- FR-006 音量設定: D2 のとおり。スライダーを動かすとすぐ反映され、効果音のスライダーを離したときに確認用の効果音を1回鳴らす。初期値は BGM 70%・効果音 80%。0% で完全に無音。保存した値は次に起動したときにも使う。
- FR-007 素材の差し替え: どの出来事にどの音を使うかを1か所（カタログのアセット）にまとめ、コードを変えずに差し替えられる。音が割り当てられていない出来事は何も鳴らさず、エラーにしない。

## 受け入れ条件と検証方法

- AC-001 (FR-005〜FR-007): 音量の値の範囲・初期値・保存と読み込み、同時発音の上限、割り当てのない出来事で鳴らさずエラーも出ないことを EditMode テストで確認する。
- AC-002 (FR-001〜FR-004): 主な出来事（レバー・リール停止・ライン成立・味方の攻撃・敵の撃破・ボタン）で効果音が鳴り、タイトル・戦闘・ボスで BGM が切り替わることを PlayMode テストで確認する（鳴らす要求が届いたことを確かめ、音そのものは確かめない）。
- AC-003 (FR-001〜FR-006): ユーザーが Editor でタイトルからステージを通しで遊び、音が出来事に合っていること、うるさすぎないこと、音量スライダーが効いて次の起動でも残っていることを確認する。差し替えたい音はこの確認の中で直す。

## 範囲外

- 声（ボイス）。
- 音の自作や加工（音量をそろえる程度の調整は Unity の設定で行う）。
- 敵の種類ごとの撃破音（全種類で共通。ボスだけ別）。
- spec 012（味方ごとの強化）の新しい攻撃方法の音。012 を再開するときに追加する。
