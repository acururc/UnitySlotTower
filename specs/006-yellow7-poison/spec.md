# 黄7の毒の演出

状態: 承認済み
承認: 2026-11-23、FR-001〜FR-007 と AC-001〜AC-005 の検証方法（ユーザー「承認」）

## 目的
spec 003（赤7）・004（青7）・005（緑7）に続き、出目の演出を1種類ずつ派手にする。4本目は黄7（全ての敵に一定時間の毒、002 FR-112。初期値は1ダメージ/秒を5秒）。今の「盤面が毒の色になり敵ごとに色が付き霧が流れる」仮の演出（002 E-28、`SlotBoardEffect` の黄7）を、毒の沼が湧いて弾ける演出に置き換える。

## 確定した決定（ユーザー回答）
- D-01 （2026-11-23）005 の次は黄7（spec 004 D-01 の1種類ずつ）。
- D-02 （2026-11-23）流れ: 盤面の地面から毒の沼がぼこぼこ湧き上がる（予兆）→ 約1秒後に沼が弾けて毒が始まる。
- D-03 （2026-11-23）毒の間は敵ごとに紫のオーラが付き、毒のダメージが入るたびに点滅する。毒が切れたら消える。
- D-04 （2026-11-23）沼が弾ける瞬間に弱い揺れ（青7より弱い）を入れる。ヒットストップは入れない。
- D-05 効果が出るタイミングは演出の山場（沼が弾ける瞬間）に合わせる（赤7 D-04・青7 D-02・緑7 D-03 と同じ考え）。作り方は spec 003 D-01・D-06 と同じ（既製の無料素材＋流れは自作、ログイン不要・有料不可）。

## 要求
- FR-001 (D-02) 黄7が揃うと、戦闘モニターの盤面の地面から毒の沼が湧き上がり、約1秒後に弾ける。
- FR-002 (D-04) 沼が弾ける瞬間に戦闘モニターが青7より弱く揺れる。ヒットストップは起こさない。揺れの強さは赤7・青7と別に調整できる。
- FR-003 (D-05) 毒は揃った瞬間ではなく沼が弾ける瞬間（揃ってから約1秒後、`slot_rules.csv` で調整）に始まり、そこから `yellow_poison_seconds` の間、今と同じダメージと間隔で全ての敵に入る。待っている間にステージが終わったら毒は始めない。一時停止中と倍速では待ち時間も止まる・速くなる。
- FR-004 (D-03) 毒の間、盤面の敵（毒の間に出てきた敵も含む）に紫のオーラが付き、毒のダメージが入るたびに点滅する。毒が切れたらオーラは消える。倒された敵のオーラはその場で消える。
- FR-005 黄7の待ちの間も黄7は発動中として抽選から外す（待ちの間にもう一度揃わない、青7 FR-005 と同じ）。
- FR-006 赤7・青7・緑7・バー・コインの演出と、図柄の光（`SlotAlignEffect`）、外枠・LED の光は今のまま。
- FR-007 演出の素材の出どころとライセンスを記録する（`docs/ASSET_LICENSES.md`）。

## 受け入れ条件と検証方法
- AC-001 (FR-001・FR-002・FR-004) Play 中に黄7を揃えると、沼が湧く→弾けて弱く揺れる→敵にオーラが付きダメージごとに点滅→毒が切れてオーラが消える、の順に出る。— ユーザーが Editor で Play して確認
- AC-002 (FR-003・FR-005) 揃ってから弾ける瞬間までは毒のダメージが入らず、弾けた瞬間から `yellow_poison_seconds` の間入る。待っている間にステージが終わったら毒は始まらない。一時停止中と倍速では待ち時間も止まる・速くなる。待ちの間と毒の間は黄7が抽選に出ない。— EditMode テスト
- AC-003 (FR-001・FR-004) 演出が終わると部品がすべて消え、毒の間に出てきた敵・倒された敵でも崩れない。— PlayMode テスト
- AC-004 (FR-006) ほかの出目の演出の既存テストが通る。— PlayMode テスト
- AC-005 (FR-007) ライセンスの記録がある（新しい素材を使った場合）。— 文書の確認
