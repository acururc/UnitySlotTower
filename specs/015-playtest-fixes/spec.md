# テストプレイの指摘への対応

状態: 承認済み
承認: 2026-11-27、FR-001〜FR-043 と AC-001〜AC-007 の検証方法（ユーザー「承認」）

## 目的

2026-11-27 のユーザーのテストプレイ（spec 014 T1707 の試聴と spec 013 T1602 の通しプレイを兼ねる）で出た指摘をまとめて直す。spec 011 の見せ場（FR-030〜FR-032）と spec 013 の範囲（ステージ2〜4は範囲外・FR-001/FR-002 の数え方）は、この spec の要求で上書きする。

## 現状（2026-11-27 確認）

- 見せ場はステージ1のウェーブ5（近接10＋遠距離4）。出そろうと盤面が止まり、賭け3枚・レバーの点滅と矢印。決め打ちは中段 赤7・上段 青7・下段 BAR。終わっても賭けは3枚のまま。暗転や大きな案内はない。
- キャラ配置の専用チュートリアルはない。ステージ1のウェーブ1〜4（近接1→2→3→4体＋遠距離2）が配置を覚える段になっている。
- 1ラインの当たり率 `line_hit_rate` = 0.6。
- 音量の初期値は BGM 0.7・効果音 0.8。BGM 3曲のカタログ音量はどれも 0.8。ステージクリアは `jingles_NES00`、ウェーブ開始は `jingles_HIT03`（0.8）、リール回転は `interface_scroll_002`（0.5）、揃いは `interface_confirmation_002`。賭け・レバー・リール停止はカジノ／金属／衝撃系の音。
- ステージ3（`battle_b`）と4（`elite_a`）は、どちらも左上と左下の出現口から中央で合流して右の本拠地へ向かう同じ形。
- ステージ5は飛行が4〜5体ずつ短い間隔でまとまって来る。飛行（射程2）が高台の弓を倒してしまう。
- ステージ6はウェーブ1の開始と同時に両方の出現口から近接3体ずつ、ウェーブ2も開始と同時に両側5体ずつ。
- 敵の HP ゲージは足元の画面下側にあり、手前の敵に隠れる。重装（盾持ち・体が大きい）はゲージ付近に灰色の大きな四角（盾）が見える。

## 確定した決定（ユーザー回答）

- D1 (2026-11-27): 見せ場の決め打ちは赤7・青7・黄7の3つ。
- D2 (2026-11-27): 見せ場はステージ1の一番初めのウェーブ（キャラ配置より先）。終わったら賭けを1枚に戻す。
- D3 (2026-11-27): 音量の初期値は真ん中。BGM は全体的に音量を下げる。

## 要求

数値は仮で、ユーザーの確認の中で直す。

### スロットの見せ場（チュートリアル）
- FR-001: ステージ1のウェーブ1を見せ場にする。ウェーブ1は近接の小さな群れ（初期値: 近接8体）。出そろったら盤面を止め、コインを補い、賭けを3枚にしてレバーを示す（止める・補う・示すは spec 011 FR-031 のまま）。元のウェーブ1〜4は2〜5へずらし、元のウェーブ5（大群）はなくす。
- FR-002: 見せ場の決め打ちは 中段 赤7・上段 青7・下段 黄7（D1）。3つの効果で群れが全滅する強さ（賭け3枚の赤7 60%＋毒 12%×5回）。
- FR-003: 見せ場の回転が終わったら賭けを1枚に戻す（D2）。
- FR-004: 見せ場の強調: 止めている間、盤面（戦闘フィールドと操作バー）を暗くし、スロット台だけを明るいまま残す。レバーを指す大きく動く矢印を出し、レバーの点滅を今より大きくする。文字あり版では「レバーを引こう！」の大きな案内を出す（文字なし版は矢印と暗転だけ）。レバーを引いたら全部消える。

### スロットの当たりやすさ
- FR-010: `line_hit_rate` を 0.6 → 0.7 にする。早見表の確率は新しい値から出る数字に変わる。

### 音
- FR-020: 音量の初期値を BGM・効果音とも 0.5 にする（D3）。BGM 3曲のカタログ音量を 0.8 → 0.5 にする。保存済みの音量（PlayerPrefs）があればそちらが使われる。
- FR-021: ステージクリアの音を、負けの音と聞き分けられる明るく上がっていくファンファーレに替える。
- FR-022: スロット系の音（賭け・レバー・リール回転・リール停止・揃い・ハズレ）を電子音（Kenney digital-audio など）に替える。リール回転は今より大きくする。
- FR-023: 揃いの音を豪華にする: 揃いの電子音に上昇音（またはジングル）を重ね、2本目・3本目の揃いでは音の高さか重なりを増やす。
- FR-024: ウェーブ開始（群れが出てくるとき）の音を控えめにする（初期値 0.8 → 0.35）。

### ステージ
- FR-030: ステージ4のマップを、ステージ3と違う形にする: 1つの出現口から出た道が中央の高台の島を挟んで上下2本に分かれ、本拠地の手前で再び合流する（中央の高台から両方の道を撃てる）。ウェーブはこの2本の道に振り分け直す（中ボスは残す）。
- FR-031: ステージ5の飛行を弱める: まとまりを1回3体まで・間隔を広げ、飛行の合計を減らす（主役は飛行のまま）。弓が置き方しだいで生き残れること。
- FR-032: ステージ6の序盤を緩める: ウェーブ1は片側から始め、反対側は遅れて来る。ウェーブ2の両側も時間差にする。両側同時の群れ（5体以上ずつ）はウェーブ4・5に残す。

### 表示の不具合
- FR-040: 文字あり版で、賭けのボタンとレバーの説明「レバー（Space）」が重ならない。
- FR-041: 操作バーのキャラの札で、名前（タンク・剣士など）の上に重なる灰色の細い長方形をなくす。
- FR-042: 敵の HP ゲージを頭の上に出し、ほかの敵や自分の体に隠れずに常に見えるようにする。
- FR-043: 大きい敵（重装・ボス）も普通の HP ゲージが見え、ゲージの位置に灰色の大きな四角が出ない（重装の盾はゲージと紛れない大きさ・位置にする）。

## 受け入れ条件と検証方法

- AC-001 (FR-001〜FR-003): PlayMode テスト（`SlotBetShowcaseTests` を更新）: ステージ1のウェーブ1が出そろうと止まり、レバーで赤7・青7・黄7の三重当たり、群れが全滅し、賭けが1枚に戻る。実データの EditMode テスト（`SlotShowcaseTests`・`StageDataTests`）: 見せ場はウェーブ1だけ、ウェーブ数と構成。
- AC-002 (FR-004): PlayMode テスト: 止めている間だけ暗転と矢印（文字あり版は案内も）が出て、レバーで消える。見た目はユーザーが Editor で確認。
- AC-003 (FR-010): EditMode `SlotSimulationTests`（1ライン 70%）と PlayMode `HelpTests`（早見表の数字）が通る。
- AC-004 (FR-020〜FR-024): EditMode/PlayMode の音のテスト（初期値 0.5、カタログの割り当て）が通る。聞こえ方はユーザーが Editor で確認。
- AC-005 (FR-030〜FR-032): 実データの EditMode テスト（`StageThemeTests` 更新、マップと経路の検証）が通る。手ごたえはユーザーが通しで確認。
- AC-006 (FR-040〜FR-043): 文字あり版の画面撮影で重なりがないことを Claude が確認し、HP ゲージと札はユーザーが Editor で確認。
