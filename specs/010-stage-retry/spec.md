# ゲームオーバーからステージをやり直す

## 目的
今はライフが0になると、ゲームオーバーのリザルトから「もう一度」を選んでもステージ1から始まる。ライフは回復せずに持ち越すので、終盤で負けると20分以上の進行を失う。負けたステージの始めからすぐやり直せるようにして、負けても続けたくなるようにする。

## 確定した決定（ユーザー回答）
- G-01 やり直すと、ライフ・所持金・スロットコイン・強化を、そのステージを始めたときの値に戻す。回数の制限はない（2026-11-26 ユーザー回答）。
- G-02 ゲームオーバーのリザルトには「このステージからやり直す」「タイトルへ」の2つだけを出す（「最初から」は出さない。2026-11-26 ユーザー指示）。クリアのリザルトは今のまま（もう一度＝ステージ1から、タイトルへ）。
- G-03 （Claude 案）やり直しはシーンを読み込み直さず、同じ Game シーンで盤面を片付けてステージを始め直す（待ち時間を短くするため）。盤上の味方・敵・弾・発動中の効果・召喚の待ち時間・バーとコインの倍率は、ステージ開始時と同じ状態（なし・初期値）になる。

## 要求
- FR-201 (G-01) ステージの開始時に、ライフ・所持金・スロットコイン・各職の強化レベルを記録する。そのステージでゲームオーバーになり「このステージからやり直す」を選ぶと、それらが記録した値に戻り、同じステージが最初のウェーブから始まる。何回でもやり直せる。
- FR-202 (G-02) ゲームオーバーのリザルトは「このステージからやり直す」「タイトルへ」の2つを、マウスのクリックとキーボード（左右で選んで Enter）で選べる。文字なしの UI ではアイコンで区別し、文字あり版では文字も出す。最初に選ばれているのは「このステージからやり直す」。
- FR-203 (G-03) やり直したステージは、盤上に味方・敵・弾・効果の演出がなく、召喚の待ち時間がなく、バーとコインの倍率が初期値で、普通にステージを始めたときと同じ状態から始まる。
- FR-204 クリアのリザルトは変わらない（「もう一度」でステージ1から、ゲーム開始時の値で始める。「タイトルへ」）。

## 受け入れ条件と検証方法
- AC-201 (FR-201) ステージ開始時の値を記録し、ステージ中にライフ・所持金・コイン・強化が変わってもやり直しで開始時の値に戻る。2回続けてやり直しても同じ値になる。— EditModeテスト（Core の記録と復元）
- AC-202 (FR-201・FR-203) ステージ2以降でゲームオーバーにして「このステージからやり直す」を選ぶと、同じステージ番号で始まり、盤上に味方・敵がなく、帯の残りの敵の数がそのステージの総数で、倍率が初期値。— PlayModeテスト
- AC-203 (FR-202・FR-204) ゲームオーバーのリザルトに「このステージから」「タイトルへ」の2つが出て、マウスとキーボードで選べる（「最初から」は出ない）。「タイトルへ」でタイトル。クリアのリザルトは「もう一度」（ステージ1から）と「タイトルへ」のまま。— PlayModeテスト＋Editor画像（文字なし・文字あり）
- AC-204 (全体) 実際に負けてからやり直すまでが短く、やり直した後に普通に遊べる。— 手動プレイ（ユーザー）

## 範囲外

- やり直しによる救済（ライフの回復、難易度を下げる提案など）
- クリアのリザルトの変更
