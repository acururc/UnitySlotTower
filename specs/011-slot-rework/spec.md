# スロットの作り直し

状態: 承認済み
承認: 2026-11-26、FR-001〜FR-033 と AC-001〜AC-006 の検証方法（FR-031/032 の変更後に再承認、ユーザー「承認」）

## 目的

sakurai スキルの全体評価のうち、スロットに関わる3項目を直す（順番は HANDOFF の spec 計画どおり）。

- #1 回すか迷いがない: 今は1枚賭けで毎回必ず当たり（`slot_patterns.csv` の20通りがすべて効果あり）、効果はすべてプラス、コインが余る。
- #2 赤7（全体ダメージ）と黄7（毒）が固定ダメージ（`red_damage` 5、`yellow_poison_damage` 1）で、後半の敵に弱い。
- #7 ステージ1にスロットの見せ場がない。

## 確定した決定（ユーザー回答）

- D1 (2026-11-26): 迷いは「賭け枚数を選ぶ」で作る。1〜3枚から選び、多く賭けるほど得が大きい。ハズレも入れる。
- D2 (2026-11-26): 賭け枚数＝有効ライン数。1枚=中段、2枚=中段＋上段、3枚=中段＋上段＋下段。揃った効果の強さも賭け枚数倍。複数ラインが同時に揃う（二重・三重）こともある。
- D3 (2026-11-26): 1回の抽選で同じ図柄が2ライン以上に揃うことはない。揃った図柄は種類ごとにすべて発動する。
- D4 (2026-11-26): 有効ライン1本あたりの揃う確率は60%（CSV で調整可）。目安は3枚でどれか揃う約94%、二重以上約65%。
- D5 (2026-11-26): 赤7と黄7のダメージは敵の最大HPの割合にする。ボスには弱める。
- D6 (2026-11-26): 枚数の掛け方（初期値は仮、CSV で調整）。赤7: 全敵に最大HPの20%×枚数（ボスは半分）。青7: 停止 3秒×枚数。緑7: 回復量×枚数（上限まで）。黄7: 毒 毎秒最大HPの4%×枚数を5秒（ボスは半分）。BAR: 攻撃力の倍率 1＋枚数（×2/×3/×4）、時間10秒。コイン: 所持金ドロップ倍率の上げ幅 +0.1×枚数（上限 ×1.5 はそのまま）。
- D7 (2026-11-26): ステージ1の見せ場は決め打ちの三重当たり。最後にウェーブ5（大群）を足し、レバーを引くまで止める（2026-11-26 の再承認で「敵が出そろったら盤面を止める」に具体化）。
- D8 (2026-11-26): 賭け枚数は1つの BET ボタンで 1→2→3→1 と切り替える。

## 要求

### 賭けとライン
- FR-001: 台に BET ボタンを1つ置く。押すたびに賭け枚数が 1→2→3→1 と変わる。枚数は文字なしで分かる（コインの絵の数など）。回転中は変えられない。枚数は次に変えるまで残る（ステージをまたいでも残る）。
- FR-002: 有効ラインは賭け枚数で決まる（D2）。有効ラインはリール上で光って分かる。
- FR-003: レバーで賭け枚数ぶんのコインを払う。コインが賭け枚数より少ないとき、賭け枚数はコインの数まで自動で下がる（最低1）。コインが0ならレバーは今と同じく引けない。

### 抽選
- FR-010: 有効ラインごとに、`slot_rules.csv` の揃う確率（初期値0.6）で揃うかを決める。揃うラインの図柄は、発動中で抽選から外す図柄（今の決まり）と、同じ回で別のラインに揃う図柄を除いた中から選ぶ（D3）。候補がなければそのラインは揃わない。
- FR-011: 止まったリールの見た目は抽選結果と一致する。揃わないと決まったラインは、有効・無効を問わず何も揃っていない（無効ラインに偶然揃って見えることもない）。
- FR-012: 揃った図柄はすべて発動する。演出は揃ったライン（中→上→下の順）ごとに少し間をあけて出す。二重・三重のときは揃った数が分かる演出を足す（仮置き、本番の見た目は後で決める）。

### 効果の強さ
- FR-020: 各効果は賭け枚数を掛けて発動する（D6）。掛け方の係数は `slot_rules.csv` で調整できる。
- FR-021: 赤7は場の全敵に最大HPの割合のダメージ。黄7の毒は毎秒最大HPの割合のダメージ。ボスには `slot_rules.csv` のボス倍率（初期値0.5）を掛ける。最低ダメージ1の決まりは残す。
- FR-022: 早見表（一時停止中のスロットのページ）を新しい決まり（賭けとライン、枚数で強くなること）に合わせる。

### ステージ1の見せ場
- FR-030: ステージ1にウェーブ5（味方だけでは止めにくい大群。初期値は近接10体＋遠距離4体、通しプレイで調整）を足す。
- FR-031: ウェーブ5の敵が全員場に出たら、盤面（敵・味方・時間の効果）を止め、コインを最低3枚まで補い、賭けを3枚にし、レバーを点滅と矢印で示す。レバーを引くまで盤面は止まったまま（D7）。
- FR-032: その1回は必ず三重当たり: 中段 赤7・上段 青7・下段 BAR。レバーを引くと盤面が動き出し、三重当たりの効果が場の大群に入る。
- FR-033: ステージ1の見せ場はそのステージで1回だけ。spec 010 のやり直しでステージ1をやり直したときは、もう一度起きる。

## 受け入れ条件と検証方法

- AC-001 (FR-001, FR-003): BET の切り替え、回転中の拒否、コイン不足で枚数が下がること — EditMode テスト（Core）＋ PlayMode テスト（ボタン）。
- AC-002 (FR-010, FR-011): 固定乱数で、1〜3枚それぞれのライン判定・同じ図柄の重複なし・発動中の図柄の除外・停止位置が結果と一致（全ライン）を確かめる。多数回の試行で1ラインの揃う割合が設定値に近い — EditMode テスト。
- AC-003 (FR-012, FR-020, FR-021): 二重・三重で各効果が枚数倍で発動、赤7・毒が最大HPの割合（ボス半分、最低1）— EditMode テスト。演出の順と間 — PlayMode テスト＋ユーザーが Editor で確認。
- AC-004 (FR-022): 早見表の内容 — ユーザーが Editor で確認。
- AC-005 (FR-030〜FR-033): ステージ1でウェーブ5が出そろうと盤面が止まり、レバーを引くまで動かない、決め打ちの三重当たりが大群に入る、やり直しで再発生 — PlayMode テスト＋ユーザーが通しで確認。
- AC-006: データ検証（`TableValidationTests`）・EditMode/PlayMode 全件・ハーネスが通る。
