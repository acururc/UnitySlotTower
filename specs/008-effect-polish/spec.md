# エフェクトの改善（当たり・弾・魔法陣）

状態: 承認済み
承認: 2026-11-23 ユーザー承認（P-01〜P-06 を含む spec 全体、FR-001〜FR-006・AC-001〜AC-005）

## 目的
ユーザーが紹介したエフェクト解説（lunch-inc.jp「ゲームでよく見るバトルエフェクト8選」前半・後半）を受けて、普段の戦闘の手応えと、揃いの演出の見栄えを上げる。spec 007 の報告で出した提案 1〜3 と、緑7（spec 005）を目立たせる案をまとめて行う。

## 確定した決定（ユーザー回答）
- D-01 （2026-11-23）spec 007 の報告の提案（1 当たりの衝撃、2 弾を雫の形にして尾を引かせる、3 バーの足元の輪を魔法陣にする）を実装する。
- D-02 （2026-11-23）緑7は相対的に地味なので、ステージ全体に大きな魔法陣を出す。
- D-03 コインの演出（予定していた spec 008）は、この spec の後に回す（spec 009）。

## 案（承認待ち。違っていれば指摘をもらって直す）
- P-01 当たりの衝撃は、味方の攻撃が敵に当たったときと、敵の攻撃が味方に当たったときの両方に出す。色で分ける（味方の攻撃＝白〜金、敵の攻撃＝赤）。
- P-02 当たりの衝撃は、近接は攻撃の瞬間、遠距離は弾が見た目で届いた瞬間に出す（ダメージが入る時点は今のまま）。普段の攻撃は回数が多いので、揺れとヒットストップは付けず、小さく短くする（記事: 中心から外へ広がる）。
- P-03 弾（味方の矢・敵の弾）は、頭が大きく尾が細い光の筋を引く。形は今の箱・球のまま、尾を足す。
- P-04 緑7の魔法陣: 揃うと盤面全体を覆う大きな魔法陣が描かれ（外側の円から内側へ順に現れる）、ゆっくり回り、だんだん明るくなる。回復の瞬間（光の柱）に強く光って広がりながら消える。今の予兆・降る光・光の柱はそのまま重ねる。
- P-05 バーの足元の輪は、小さな魔法陣に置き換える（縮まりながら回る）。芯・吸い込まれる粒・爆発は spec 007 のまま。
- P-06 魔法陣の絵は Editor のスクリプトで描いて PNG にする（円・目盛り・小円・三角・放射線の組み合わせ）。文字や、宗教・政治の印に見える星形（五芒星・六芒星・八芒星など）は使わない（記事の注意）。緑とバーで模様を変える。

## 要求
- FR-001 (D-01・P-01・P-02) 味方の攻撃が敵に当たると、敵の位置に小さな衝撃（光が中心から外へ広がり、粒が散る）が出る。近接は攻撃の瞬間、遠距離は弾が届いた瞬間。敵の攻撃が味方に当たったときも同じように、色を変えて出る。揺れ・ヒットストップはない。
- FR-002 (D-01・P-03) 弾は飛ぶ間、後ろに頭が太く尾が細い光の筋を引く。弾が消えたら筋も残らない。
- FR-003 (D-02・P-04・P-06) 緑7が揃うと盤面全体に大きな魔法陣が現れて回り、回復の瞬間に強く光って消える。待っている間にステージが終わったら、魔法陣は静かに消える。
- FR-004 (D-01・P-05・P-06) バーの溜めの間、味方の足元に小さな魔法陣が縮まりながら回る（spec 007 FR-001 の光の輪の置き換え）。
- FR-005 戦闘の数値（ダメージ・時間・倍率）は変えない。ほかの出目の演出と既存の表示は今のまま。
- FR-006 新しい素材を使った場合は出どころとライセンスを記録する（`docs/ASSET_LICENSES.md`）。魔法陣の絵は自作。

## 受け入れ条件と検証方法
- AC-001 (FR-001〜FR-004) Play 中に、攻撃が当たると衝撃が出て、弾が尾を引き、緑7で盤面に大きな魔法陣、バーで足元に魔法陣が出る。— ユーザーが Editor で Play して確認
- AC-002 (FR-001・FR-002) 当たりの衝撃は、攻撃（近接）・弾の到着（遠距離）の数だけ出て、粒の数に上限があり、終われば残らない。弾が消えたら尾も消える。— PlayMode テスト
- AC-003 (FR-003・FR-004) 魔法陣は緑7・バーの流れに合わせて出て、終われば消え、部品が残らない。— PlayMode テスト
- AC-004 (FR-005) 既存の EditMode・PlayMode テストが通る。— テスト
- AC-005 (FR-006) 素材の記録がある、または新しい素材がない。— 文書の確認
