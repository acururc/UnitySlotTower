# バーの闘気の演出

状態: 承認済み
承認: 2026-11-23 ユーザー承認（spec 全体、FR-001〜FR-007・AC-001〜AC-005）

## 目的
spec 003〜006（赤7・青7・緑7・黄7）に続き、出目の演出を1種類ずつ派手にする。5本目はバー（全ての味方の攻撃力が一定時間上がる、002 FR-112。初期値は10秒間2倍）。今の「味方の頭上に上向きの矢印が出る」仮の演出（002 E-28、`SlotBoardEffect` のバー）を、味方から闘気が立ちのぼる演出に置き換える。

## 確定した決定（ユーザー回答）
- D-01 （2026-11-23）006 の次はバー（spec 004 D-01 の1種類ずつ）。
- D-02 （2026-11-23）流れ: 味方の足元に光の輪が縮まっていく（溜め）→ 約1秒後に味方ごとに炎のような闘気が爆発して攻撃力アップが始まる。
- D-03 （2026-11-23）効果の間は味方ごとに闘気のオーラが付き、攻撃するたびに火花が出る。効果が切れたら消える。
- D-04 （2026-11-23）闘気が爆発する瞬間に弱い揺れ（黄7と同じくらい）を入れる。ヒットストップは入れない。
- D-05 効果が出るタイミングは演出の山場（闘気が爆発する瞬間）に合わせる（赤7 D-04・青7 D-02・緑7 D-03・黄7 D-05 と同じ考え）。作り方は spec 003 D-01・D-06 と同じ（既製の無料素材＋流れは自作、ログイン不要・有料不可）。

## 要求
- FR-001 (D-02) バーが揃うと、戦闘モニターの味方の足元に光の輪が縮まっていき、約1秒後に味方ごとに闘気が爆発する。
- FR-002 (D-04) 闘気が爆発する瞬間に戦闘モニターが弱く揺れる（黄7と同じくらい）。ヒットストップは起こさない。揺れの強さはほかの出目と別に調整できる。
- FR-003 (D-05) 攻撃力アップは揃った瞬間ではなく闘気が爆発する瞬間（揃ってから約1秒後、`slot_rules.csv` で調整）に始まり、そこから `bar_seconds` の間、今と同じ倍率で全ての味方に効く。待っている間にステージが終わったら始めない。一時停止中と倍速では待ち時間も止まる・速くなる。
- FR-004 (D-03) 効果の間、盤面の味方（効果の間に置いた味方も含む）に闘気のオーラが付き、味方が攻撃するたびにその味方から火花が出る。効果が切れたらオーラは消える。倒された・撤退した味方のオーラはその場で消える。
- FR-005 バーの待ちの間もバーは発動中として抽選から外す（待ちの間にもう一度揃わない、青7 FR-005・黄7 FR-005 と同じ）。
- FR-006 赤7・青7・緑7・黄7・コインの演出と、図柄の光（`SlotAlignEffect`）、外枠・LED の光は今のまま。
- FR-007 演出の素材の出どころとライセンスを記録する（`docs/ASSET_LICENSES.md`）。

## 受け入れ条件と検証方法
- AC-001 (FR-001・FR-002・FR-004) Play 中にバーを揃えると、足元の輪が縮まる→闘気が爆発して弱く揺れる→味方にオーラが付き攻撃ごとに火花→効果が切れてオーラが消える、の順に出る。— ユーザーが Editor で Play して確認
- AC-002 (FR-003・FR-005) 揃ってから爆発の瞬間までは攻撃力の倍率が1のままで、爆発の瞬間から `bar_seconds` の間上がる。待っている間にステージが終わったら始まらない。一時停止中と倍速では待ち時間も止まる・速くなる。待ちの間と効果の間はバーが抽選に出ない。— EditMode テスト
- AC-003 (FR-001・FR-004) 演出が終わると部品がすべて消え、効果の間に置いた味方・倒された味方でも崩れない。— PlayMode テスト
- AC-004 (FR-006) ほかの出目の演出の既存テストが通る。— PlayMode テスト
- AC-005 (FR-007) ライセンスの記録がある（新しい素材を使った場合）。— 文書の確認
