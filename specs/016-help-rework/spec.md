# 早見表（ヘルプ）の作り直し

状態: 承認済み
承認: 2026-11-27、FR-001〜FR-014 と AC-001〜AC-003（ユーザー「承認進めてください」）

## 目的

一時停止中に開く早見表（`HelpScreen`）を、文字なし版・文字あり版のどちらでも一目で分かる内容に作り直す。今は意味の分からない数値・倍率・計算式、伝わらないアイコン、文字の重なりやはみ出しがあり、とても分かりにくい（ユーザー、2026-11-27）。

## 現状（2026-11-27、撮影 `Artifacts/Automation/Editor/t359/20261127-180721/*-help-*.png`）

- スロットのページ: ハズレと6図柄の行。各行に「確率（ライン1本あたりの %）▶ 効果アイコン＋数値（-20%・×0・+50%・-4%・×2.0・×1.1）」と2つ目の数値（時計＋秒数、コインは ▲×1.5 の上限）。文字ありは右側に1行の説明（「コイン：このステージの獲得金アップ」は枠からはみ出す）。下に賭け1〜3枚とその時に有効な段の図があり、説明はない。
- 味方のページ: 4職業の行。本体の絵・右向きの範囲図・7つの数値（HP・攻撃力〔バッファーは ×2.0〕・防御・攻撃間隔・ブロック数・コスト・再配置の待ち）。文字ありはアイコンがラベルの字に重なる（HP・ブロック数・攻撃間隔など）。
- 組み立ては Editor の Setup（`HelpScreenSetup`・`HelpPagesSetup`・`SlotBetHelpSetup`）。値は開くたびに `HelpScreen.Refresh` が CSV から書く。

## 確定した決定（ユーザー回答）

- D1 (2026-11-27): 数値は最小限にする。何が起きるかは絵（文字ありは短い文も）で示す。数値は意味がすぐ分かるもの（秒数・コストなど）だけ単位つきで残し、確率・倍率・上限などは載せない。
- D2 (2026-11-27): ページを増やす。スロットの回し方（賭け枚数と有効な段）・図柄の効果・味方に加えて、敵の種類と基本の遊び方のページも作る。
- D3 (2026-11-27): 文字なし版では、何が起きるかを各行の動く小さな図（くり返す短い演出）で見せる。
- D4 (2026-11-27): 敵のページには6種類（近接・遠距離・飛行・重装・中ボス・最終ボス）を最初からすべて載せる。

## 要求

### 全体
- FR-001: 早見表は5ページ。順に「遊び方」「スロットの回し方」「図柄の効果」「味方」「敵」。上のタブ（各ページの絵のアイコン、文字ありは名前も）と ◀ ▶ で切り替え、◀ ▶ は端で反対の端へ回る。開閉の操作（一時停止中の ? ボタン・?（/）キー・◀ の閉じる・再開で閉じる）は今どおり。
- FR-002: 動く図は一時停止中も動く（ゲームの時間ではなく実時間で動く）。開いているページの図だけを動かし、閉じたら止める。
- FR-003: 文字なし版は文字を使わない（数字と ¥・秒の記号は可）。文字あり版は同じ図に短い文を添える。文字ありの文は枠からはみ出さず、アイコン・数字・ほかの文と重ならない。
- FR-004: 載せる数値は次だけ（D1）。図柄の効果の続く秒数（青7・黄7・バー）、味方のコストと再配置の待ち秒数、味方のブロック数（盤面の UI と同じ壁と赤い三角の表し方）。どれも CSV の今の値を開くたびに出す。確率・倍率・割合・上限・HP・攻撃力・防御・攻撃間隔は出さない。

### 各ページの中身（図と文字ありの文の案。言い回し・絵は実装中にユーザーと詰める）
- FR-010 遊び方: (1) 敵は道を通って本拠地へ向かい、着くとライフが減る、0 で負け。(2) 下の札を選び、置けるマスに置いて向きを決める（タンク・剣士は地面、弓・バッファーは高台）。置くとお金（¥）が減る。(3) 敵を倒すとお金とコインが出る。お金は味方を置くのに、コインはスロットに使う。
- FR-011 スロットの回し方: コインを1〜3枚賭けてレバーを引く。1枚は中段、2枚は上段も、3枚は下段も有効になる（有効な段が光る図）。有効な段に同じ図柄が3つ横に揃うと、その効果が起きる。
- FR-012 図柄の効果（7行、ハズレは載せない）: 赤7 敵全員にダメージ / 青7 敵全員が N 秒止まる / 緑7 味方全員の HP が回復 / 黄7 敵全員が N 秒毒を受ける / バー N 秒 味方の攻撃力が上がる / コイン このステージで敵が落とすお金が増える（重ねて揃うほど増える）。各行に図柄の絵と動く図。
- FR-013 味方（4行）: 本体の絵、置く場所（地面／高台）、右向きの攻撃範囲図（今の図を引き継ぐ）、ブロック数、コスト ¥、再配置の待ち秒数、役割の動く図。役割: タンク 敵を多く止める（攻撃しない）/ 剣士 敵を止めて斬る / 弓 遠くの敵を撃つ、空の敵を先に狙う / バッファー 範囲内の味方の攻撃力を上げる。
- FR-014 敵（6行）: 敵の絵と特徴の動く図。近接 道を歩いて味方に止められる / 遠距離 離れた味方（高台も）を撃つ / 飛行 止められず、弓だけが攻撃できる / 重装 硬く、弓のダメージが半分 / 中ボス ステージ4の最後に出る、止めるのに枠を2つ使う / 最終ボス ステージ8の最後に出る、周りの味方をまとめて攻撃する。

## 受け入れ条件と検証方法

- AC-001 (FR-001・FR-002): 一時停止で開き、タブと ◀ ▶（端で回る）で5ページを切り替えられ、開いたページの図だけが一時停止中も動く。閉じる・再開で閉じる。— PlayMode テスト（今の `HelpTests` を5ページに直す）
- AC-002 (FR-003・FR-004): 文字ありの全ページで、文が枠に収まり（TMP のはみ出しなし）、文・数字・アイコンの枠が互いに重ならない。文字なしでは文字のテキストがない。数値は FR-004 の項目だけが CSV の値どおり。— PlayMode テスト（両方の版で全ページの文字・アイコンの矩形を調べる）
- AC-003 (FR-010〜FR-014): 撮影（Capture Screens に5ページ×2版を足す）で配置を確かめたうえで、ユーザーが Editor で両方の版の早見表を見て、数値の意味で迷わず、何が起きるか分かることを確認する。絵・文の直しはこの確認の中で行う。
