# 緑7の回復の演出

状態: 承認済み
承認: 2026-11-23、FR-001〜FR-006 と AC-001〜AC-005 の検証方法（ユーザー「承認」）

## 目的
spec 003（赤7）・004（青7）に続き、出目の演出を1種類ずつ派手にする。3本目は緑7（全ての味方の HP が回復、002 FR-112）。今の「盤面が緑になり味方ごとに緑の粒が上がる」仮の演出（002 E-28、`SlotBoardEffect` の緑7）を、天から光が降り注いで味方が回復する演出に置き換える。

## 確定した決定（ユーザー回答）
- D-01 （2026-11-23）004 の次は緑7（spec 004 D-01 の1種類ずつ）。
- D-02 （2026-11-23）流れ: 盤面の上端が緑に光る（予兆）→ 光の粒が盤面に降り注ぐ → 味方ごとに光の柱が立ち、その瞬間に回復する → 粒が上がって消える。
- D-03 （2026-11-23）回復は光の柱が立つ瞬間（揃ってから約1秒後、データで調整）に入れる（赤7 D-04・青7 D-02 と同じ考え）。待っている間に倒れた味方は回復しない。
- D-04 （2026-11-23、仮）回復はやさしい演出なので、ヒットストップと揺れは入れない。作り方は spec 003 D-01・D-06 と同じ（既製の無料素材＋流れは自作、ログイン不要・有料不可）。

## 要求
- FR-001 (D-02) 緑7が揃うと、戦闘モニターの上端が緑に光り、光の粒が盤面に降り注ぎ、味方ごとに光の柱が立ち、粒が上がって消える。
- FR-002 (D-03) 回復は揃った瞬間ではなく光の柱の瞬間（揃ってから約1秒後、`slot_rules.csv` で調整）に、その時点で生きている味方全員（待ちの間に置いた味方も含む）へ入る。回復量は今と同じ `GreenHealRate`。待っている間にステージが終わったら回復しない。一時停止中と倍速では待ち時間も止まる・速くなる。
- FR-003 (D-04) 緑7ではヒットストップと揺れを起こさない。
- FR-004 待ちの間に緑7がもう一度揃ったら、それぞれ別に回復と演出が入る（002 E-26 のとおり緑7は抽選から外さない）。
- FR-005 赤7・青7・黄7・バー・コインの演出と、図柄の光（`SlotAlignEffect`）、外枠・LED の光は今のまま。
- FR-006 演出の素材の出どころとライセンスを記録する（`docs/ASSET_LICENSES.md`）。

## 受け入れ条件と検証方法
- AC-001 (FR-001・FR-003) Play 中に緑7を揃えると、予兆→光が降る→光の柱（HP ゲージが伸びる）→粒が消える、の順に出て、揺れない。— ユーザーが Editor で Play して確認
- AC-002 (FR-002・FR-004) 揃ってから柱の瞬間までは HP が増えず、柱の瞬間に生きている味方全員が回復する。待っている間にステージが終わったら回復しない。一時停止中と倍速では待ち時間も止まる・速くなる。続けて2回揃うと2回回復する。— EditMode テスト
- AC-003 (FR-001) 演出が終わると部品がすべて消え、続けて揃っても崩れない。— PlayMode テスト
- AC-004 (FR-005) ほかの出目の演出の既存テストが通る。— PlayMode テスト
- AC-005 (FR-006) ライセンスの記録がある（新しい素材を使った場合）。— 文書の確認
