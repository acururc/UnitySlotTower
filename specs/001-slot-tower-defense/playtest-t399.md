# T399 通しの再プレイ記録

[tasks.md](tasks.md) の T399（AC-051・AC-052・AC-053・AC-056）。T375 の指摘を受けた M3W（spec D-92〜D-100）の変更を、通しで遊んで確かめる。設定は何でもよい（1回は最後まで）。1回は文字あり版でも遊ぶ。感想は短くてよく、このファイルに直接書くか、チャットで伝えてもらえれば Claude が書き写す。

## 遊び方
- Unity Editor で `Assets/UnitySlotTower/Scenes/Title` を開いて Play。▶ → 設定（1〜6）を選ぶ。
- 文字あり版: タイトルのロゴの右下の隅（見えないボタン）を押すと切り替わる。
- 一時停止中に「?」で早見表、一時停止中にスキルのゲージを押すとスキルの説明が出る。

## 確かめること
「前の指摘」は [playtest-t375.md](playtest-t375.md)。括弧は調整する所（CSV は `Assets/UnitySlotTower/Data/Tables/`）。

| # | 前の指摘 | 変えたこと | 見る所 | 調整する所 |
|---|---|---|---|---|
| 1 | UI がダサい・見づらい | 両方の版の UI を作り直した（上端の帯、角を切った板、札、詳細の板、ほかの画面） | 見た目と見やすさ。気になる画面があれば名前を | 配置・色は Claude が直す |
| 2 | 文字あり版で空中の敵が上端の UI に隠れる | 帯を細くし、盤面と飛ぶ高さが隠れないようにした | 上のほうの空中の敵が見えるか | — |
| 3 | 文字なし版で意味が分からない（ブロック数・スキル） | 札・詳細・向き選びにブロック数（壁と三角、0 は赤い ×）、スキルの絵、一時停止中のスキルの説明アニメ | 説明なしで「何体止められるか」「スキルで何が起きるか」が分かるか | — |
