## 4. 進行と画面遷移（FR-005, FR-010, FR-013〜016）

```text
Title（ロゴだけ文字可） → 難易度選択（設定1〜6の筐体プレート） → Game
Game: [リールのカスタム] → [S1-W1 準備] → [S1-W1 戦闘] → [S1-W2 準備（配置は残る）] → [S1-W2 戦闘・中ボス]
      → [S1 クリア: ライフボーナス加算・ストック化・ライフ回復] → [S2-W1 準備] … → [S3-W2 最終ボス撃破]
                                                     ↘ ライフ0 → リザルト（ゲームオーバー）
最終ボス撃破 → リザルト（クリア） → リトライ（同じ難易度で Game をやり直す）/ Title
```

- シーンは `Title`（難易度選択を含む）と `Game` の2つ。リールのカスタムとリザルトは Game 内のオーバーレイ。リトライは Game の再読み込みで初期化する（AC-004）。リトライではリールのカスタムを空きからやり直す（1プレイ通しのため）。リザルトは結果のアイコン（クリア＝王冠、ゲームオーバー＝×）、到達したステージ-ウェーブ、所持コインを出し、▶ でリトライ・◀ でタイトル（T402 で決定）。
- 準備フェーズ（C-2）: 各ウェーブ開始時、敵が出る前に配置できる時間を設ける。制限時間はなく、開始ボタン（▶）で戦闘が始まる。準備中は召喚の待ち時間を無視する（C-3）。スロットも回せる。
- ステージ内のウェーブ終了時（W1）: 配置・HP・ライフはそのままで W2 の準備に入る。ライフボーナス・ストック化・ライフ回復はしない。
- ステージ終了時（W2）: 配置中の味方を種類ごとに数えて無料ストックに加算し、全員をフィールドから外す。ライフを満タンに戻し、残りライフ×係数のコインを加算し、次のステージの準備に入る（2026-11-04: ステージ間のカスタムは廃止。カスタムはゲーム開始時だけ）。
- カスタム中は戦闘が進まず（敵はいない）、スロットも回せない。
- 無料ストックがある種類は、コインを使わずストックから配置する（ストックを先に消費）。
- 実装の解釈（T304）: 準備中の召喚は待ち時間で拒否されず、待ち時間も始めない（戦闘開始時はどの種類も待ち時間0）。戦闘中のストックからの配置はコインを使わないだけで、待ち時間は通常の召喚と同じにかかる。使わなかったストックは次のウェーブ以降に残る。ウェーブの終わりは「出現予定の敵がすべて出て、フィールドに敵がいない」とき。
- ライフ: 敵が1体ゴールに着くたびに、その敵の「ライフ減少量」だけ減る（中ボスは複数、最終ボスは全ライフを想定）。

## 5. ルールの詳細（承認済み要求の実装解釈）

### 味方（FR-020〜028）
- ステータス: 最大HP、攻撃力、防御力、攻撃間隔、攻撃範囲（向き基準のマス相対座標の集合）、ブロック数、配置マス種別、召喚コスト、待ち時間。
- ダメージ式（アークナイツ準拠）: `max(攻撃力 − 防御力, 攻撃力 × 0.05)`。
- 攻撃対象: 範囲内でゴールに最も近い敵。弓だけが空中敵を対象にできる。剣士とタンクはブロック中の敵を優先する。
- ヒーラー: 範囲内で HP 割合が最も低い味方（満タンだけなら回復しない）。
- 役割は `units.csv` の `role`（`melee` 近距離・`ranged` 遠距離〔空中も狙える〕・`heal`）で持つ。回復量は（強化後の）攻撃力で、最大HPを超えない。味方は `tank`/`sword`/`archer`/`healer` の4種（2026-11-01 にバッファー `buffer`・役割 `buff`・列 `buff_rate` を廃止）。
- スロットの効果（D-45）: 攻撃力アップ・攻撃速度アップは戦闘全体の倍率として持ち、効果中は配置中の味方と効果中に新しく置いた味方の全員に効く。攻撃力アップは攻撃と回復の両方に掛け、攻撃速度アップは攻撃間隔を倍率で割る。残り時間は戦闘のステップで数えるので、準備中・一時停止中・カスタム中は減らず、ステージをまたいで持ち越す。効果中に再成立したら残り時間に持続時間を足す。全体HP回復は成立した瞬間に配置中の味方全員へ最大HPの割合を足す（最大HPまで、四捨五入）。
- 対象の判定: 敵は中心が入っているマスで範囲に入る。ブロック中の敵は範囲に関係なく優先して狙う。同じ条件なら先に出た敵、回復は先に配置した味方。攻撃・回復の対象がないあいだは攻撃間隔を消費しない。
- 1ステップの順序: 出現 → 移動（ゴール到着でライフ減少） → 敵の攻撃 → HP0の味方の消滅（ブロックしていた敵は再び進む） → 味方の行動 → HP0の敵の消滅（ブロックの空きを戻し、ドロップを抽選）。ライフは0で止まり、ゲームオーバーになったら戦闘は進まない。
- 強化: 種類ごとに段階 1〜5。段階ごとの倍率（HP・攻撃・防御）と費用をテーブルで持つ。強化した瞬間、配置中の同種全個体のステータスを再計算する（最大HPが増えた分は現在HPにも加算）。
- 撤退: 個体を消し、`召喚コスト × 返還率` を切り捨てで返す。ストックから出した個体も、その種類の召喚コストを基準に返す（C-3）。
- 配置上限: フィールド上の味方の総数。ストックからの配置も上限に数える（C-3）。

### 敵（FR-030〜033）
- ステータス: HP、攻撃力、防御力、攻撃間隔、移動速度、射程、空中フラグ、ブロック消費数（ボスは2以上）、ライフ減少量、ドロップ確率、ドロップ量（最小〜最大）。
- 近距離雑魚: ブロックされると、ブロックした味方を攻撃する。遠距離雑魚: 移動しながら、射程内の味方（高台を含む）を攻撃する。ブロックされると停止する。空中雑魚: ブロックされず、空中経路を進み、射程内の味方を攻撃する。
- ブロックの位置: 地上の敵は、ブロックの空きが消費以上ある味方のマスの手前の境界（マス中心の 0.5 マス手前）で止まる。既にそのマスの中に居れば、その場で止まる（2026-10-30 ユーザー確認）。
- ドロップ: 味方に倒されたときだけ、ドロップ確率で当たれば量を最小〜最大（両端を含む一様）で決める。ゴールに着いた敵は落とさない。乱数は戦闘に注入する（シード固定で再現できる）。
- 中ボス・最終ボス: 高HP・高ブロック消費。中ボスは固有の行動を持たず、ステータスだけが強い。最終ボスはステータスに加えて範囲攻撃を持つ（2026-10-30 ユーザー決定）。
- 範囲攻撃（T306）: `enemies.csv` の `area_atk`（0 なら持たない）・`area_radius`（マス）・`area_interval`（秒）。出現から1間隔後に、敵の位置から半径内にマス中心がある味方全員を `area_atk` で攻撃する（ダメージ式は通常と同じ）。半径内に味方がいないあいだは間隔を消費しない。通常の攻撃とは別に行う。
- クリア: 最終ボスを倒しても、残りの敵を全滅させるまではクリアにしない（最終ウェーブの終了＝クリア。2026-10-30 ユーザー決定）。最終ボスはゴールに着くと全ライフを失わせる。

### スロット（FR-040〜048、2026-11-01 改訂）
- 構成（2026-11-04 改訂）: 3リール × 18コマ（`slot_rules.csv` の `reel_length`）、3段表示。3本とも同じ配列。有効ラインは上段・中段・下段の横3本と斜め2本の計5本（D-52、2026-11-06 改訂。D-58）。固定掛け金は 3枚。
- 図柄: 攻撃力アップ（`atk`）・攻撃速度アップ（`speed`）・全体HP回復（`heal`）・コイン（`coin`）・7（`seven`）・BAR（`bar`）。
- 抽選（D-43）: レバーオン時に、設定ごとのハズレ率（`slot_settings.csv`）で当たり/ハズレを決める。当たりなら、配列での各図柄のマス数に比例した重みで揃う図柄を1つ決める。
- 出目（D-44・D-53、2026-11-04 改訂）: ストップボタンを押した位置から下へ1コマずつ進め、「その位置で止めても、まだ止めていないリールの止め方で最終形が作れる」最初の位置で止める（最大 `reel_length − 1` コマ滑る）。最終形の条件: 当たりは結果の図柄が5本の有効ラインのちょうど1本に3つ揃い、残りのラインは揃わない。ハズレはどのラインも3つ揃わない（2026-11-06 改訂: 斜め2本を追加）。押す順は自由で、押した位置は結果を変えない。作れるかは残りのリールの全位置の総当たりで調べる（18コマなら最大 18² 通り、押した瞬間だけ）。ロック配置（下記）により、空きマスに何を入れても当たりの最終形は必ず作れる（7・BAR のように少ない図柄も2か所あり、リールごとに違う場所で止めて上下の段をずらせる）。
- 払い出しと効果: コイン揃いは `coin_payout` 枚を払う。攻撃力アップ・攻撃速度アップ・全体HP回復は戦闘へ効果を渡す（味方の節）。効果の図柄は払い出しなし。
- ボーナス（D-33/D-40）: 7揃いで BIG、BAR揃いで REG。ボーナス中は `big_games`/`reg_games` ゲームのあいだ掛け金なしでレバーを引け、毎ゲーム コインが揃って `big_payout`/`reg_payout` 枚を払う（ハズレ抽選なし、出目はコイン揃い）。消化し終えると通常に戻る。
- ウェイト（初期値 2.0 秒、前のレバーオンから数え、待ち中に押したレバーは時間が来たら回す。回転中のレバーは無視）は従来どおり。
- リールのカスタム（D-46〜D-51、2026-11-04 改訂）: ロック配置は `slot_locked_reel.csv`（旧 `slot_default_reel.csv` を GUID ごと改名。`reel_length` 行で、各行は図柄 id か `empty`）。初期値は 18マスで `攻・速・コ・BAR・コ・7・空・空・空・BAR・速・回・攻・7・回・空・空・空`（6図柄×2 をロック、空き6。同じ図柄が隣り合わない。空きマスの埋め方 4⁶ 通りすべてで全結果の最終形が作れることを総当たりで確認済み）。データ検証: 6図柄がちょうど2つずつロックされ、空きの埋め方すべてで全結果の最終形が作れること（EditMode）。Core `ReelCustomizer` はロックと空き（図柄なし）を持ち、空きマスか入れたマスへの「入れる（上書き）」と「外す」だけを受け付け、ロックへの操作は拒否する。空きがなくなったら確定できる。画面: マスは 9マス×2段（上段が 1〜9、下段が 10〜18。リールの並び順）。ロックは鍵の印付きで暗く、空きは点線の枠。下に入れられる4図柄（攻・速・回・コ）を並べ、マウスはそこからマスへドラッグ＆ドロップ、入れたマスから外へドラッグすると外す。キーボードは 3章。空きが残っているあいだは ✔ が押せず、空きマスの枠を点滅させる。表示: ハズレ率・当たり率と当たり時の各図柄の確率（埋まっているマスのうちのマス数 ÷ 埋まっているマス数。全部埋まれば総マス数と同じ）。% は小数1桁に四捨五入。カスタムはゲーム開始時の1回だけ（D-48）で、ゲーム開始時は空きがすべて空（前回の配列は使わない）。
- 筐体の仮表示: ボーナス中ランプと残りゲーム数、クレジット、直前の払い出し。効果の残り秒数は操作バー（2章）。

## 7. マップとウェーブ（FR-010）

- グリッドは 9列×6行を基本にする。戦闘が上部60%に広がるので、T317 の画像確認でマスの大きさとカメラを合わせる（必要ならマップを広げる。データだけで変えられる）。T317 では 9×6 のままカメラだけ合わせた（フィールドの上下に余白が残る。広げるかは T309 の手動プレイで判断）。
- 既存のマップを流用する: S1 ← 旧 w2（S字の一本道）、S2 ← 旧 w4（出現口2つ＋空中路）、S3 ← 旧 w5（地上路2本＋空中路）。

## 8. 文字を使わない UI（FR-003, FR-004）

- フォントは数字（0-9）・小数点（カスタム画面の%用、T316）と記号（+ − × / % ?。? は T404 の説明ボタン用）だけを含む TextMeshPro フォントアセットを使う。それ以外の文字はそもそも表示できない作りにする。
- 自動チェック: シーン（Title はロゴ以外。難易度選択も対象）とプレハブの全テキスト部品を走査し、数字・記号以外の文字があるか数字専用フォント以外を使っていれば失敗する EditMode テストを用意する（AC-001 を補う）。実行中にコードが入れる文字は、各画面を開いて調べる PlayMode テスト（`ScreenTextTests`、T406）で確かめる。
- 説明の見せ方: 各要素を初めて使う場面（例: W1 開始時の召喚、初めてのボーナス）で画面を薄暗くし、対象を光らせて矢印と手のアイコンのアニメで操作を示す。一時停止中は「?」アイコンから、図柄＝効果（倍率・秒数・払い出し）の早見表と現在のハズレ率・各図柄の確率、味方の能力（範囲図・数値）を見られる。
- 文字なし説明の進め方（T403、2026-11-04 ユーザー決定）: 1回のプレイの中で題目ごとに一度だけ出す（リトライ・タイトルから始め直すとまた出る。保存はしない）。説明中は戦闘の時間だけを止め（`BattleController.IsHeldByGuide`。スロットと操作は動く）、示した操作を実際に行うと次へ進む。暗幕は対象の周りだけを空け、暗い部分のクリックは通さない（キーボードは通す）。進行の判定は Core の `GuideSequence`、表示は Runtime の `GuideOverlay`。
  - 出す場面と終わる操作: カスタム（開始時のカスタム画面。画面自体が暗いので暗幕なし。2026-11-04 改訂: 手のアイコンが下の図柄から最初の空きマスへドラッグする動きを繰り返し、空きがなくなったら ✔ を指す。✔ で閉じる）→ 召喚・配置・向き（カスタム後。1体置くまで、操作の段階に合わせて アイコン→マス→向きの矢印）→ スロット（最初の1体の後。レバー→ストップ、リールが止まるまで）→ ボーナス（初めてボーナスに入ったとき。ランプとレバー、次のレバーまで）→ 強化（配置中の種類を初めて強化できるようになったとき。強化するまで）→ 撤退（ステージ内のウェーブ2以降の準備で味方がいるとき。味方→撤退アイコン。▶ で始めたら終わり）。
  - 示した操作ができなくなったら（コイン不足など）終えずに引っ込め、また条件がそろえば出す。一時停止中は隠す。
- 一時停止中の早見表（T404）: 戦闘の右下（操作バーの一時停止ボタンの上）に「?」を出し、押すと画面全体の早見表を開く（Runtime `Flow/HelpScreen`）。上はスロット: ハズレ率と、6図柄それぞれの通常時の1ゲームあたりの確率（当たり率 × マス数 ÷ 総マス数。カスタム画面の「当たり時の%」とは違う）と効果（7・BAR はコインのアイコンに「+1ゲームの払い出し×ゲーム数」、攻撃力・攻撃速度アップは「×倍率」と時計に秒数、全体HP回復は「+%」、コインはコインのアイコンに「+払い出し」）。下は味方4種: 本体の色、右向きの範囲図（本人のマスに ▶）、現在の強化段階の HP（緑のゲージ）・攻撃（赤い ▶。回復役は回復の図柄）・防御（青い盾）・攻撃間隔（時計）と、ブロック数（壁と止まる敵）・コスト（コイン）・待ち時間（ゲージ）。値は開くたびに読み直す。
- 状態は色と形で区別する: 召喚可能（明るい）、コスト不足（暗い＋コインアイコン赤）、待ち時間中（円形ゲージ）、ストックあり（数字バッジ）。

### 16.7 ルート（FR-010, FR-017）
- `route_rules.csv`（キーと値: `floors`〔8〕・`columns`〔4〕・`paths`〔4〕・`weight_battle`〔50〕・`weight_elite`〔14〕・`weight_exchange`〔10〕・`weight_shop`〔12〕・`weight_rest`〔14〕・`elite_min_floor`〔3〕・`rest_heal`〔3〕・`shop_slots`〔3〕・`exchange_money_per_coin`〔2〕）。
- 生成（Slay the Spire 式）: 1階は `first` の1マス、最上階はボスの1マス、その直前の階は全部回復。間の階は、`paths` 本の道を1階から列を ±1 ずつ動かしながら上へ引き（交差しない）、通ったマスを残す。各マスの種類は重みで選ぶ（`elite_min_floor` 未満は強敵なし、同じ道で両替所・ショップ・回復が続かない）。同じシードで同じルート（AC-010）。
- マスの種類は文字列 id（`battle` など）で持ち、Core `RouteNodeKinds` の登録表と Runtime の画面の登録表（id → 画面）を足せば増やせる（D-69）。検証器は `route_rules` と登録表の食い違いをエラーにする。
- `RouteMap.CanMove(from, to)`、`RunState.Enter(node)` で現在地を進める。選べるのは今のマスにつながった上の階のマスだけ。
- 画面: Game シーンの全画面オーバーレイ（3:4）。下から上へ階を並べ、マスは種類のアイコン、つながりは線、選べるマスは光る。上端にライフ・所持金・コイン・ゲージ。両替所・ショップ・回復も全画面オーバーレイで、◀ でルートに戻る（回復は入った時点で回復して ◀ だけ）。戦闘マスでは戦闘フィールドと筐体を出し、終わったらルートに戻る。

### 16.8 画面と流れ（FR-005）
- シーンは `Title` と `Game` のまま。Game に `RunController`（`RunState` を作り、ルート → 各マス → ルート を回す。戦闘は `BattleController` に `BattleNodeRun` を渡す）。リザルトは到達した階・所持金・コインを出す（クリアは王冠）。リトライは Game の再読み込みでルートも作り直す。
- 筐体（下部40%）: リール窓（3×3）、レバー、コインの数、回数固定の残り回数（コインの代わりに表示）。ストップボタン・ボーナスランプ・払い出しは消す。
- 操作バー: 味方4種のアイコン（コストは所持金のアイコンに）、各アイコンにその色のゲージ（5つの点）、満タンで光りクリックで発動（アイコン本体のクリックは召喚の選択のまま。ゲージ部分を別ボタンにする）、ライフ、所持金、ウェーブ n/2、バーの倍率（攻撃力の印に `×1.3` など）、コインの倍率（所持金の印に `×1.2`）、一時停止。旧 攻撃力・攻撃速度アップの残り秒数は消す。

### 16.11 テストと順序
- 順序: お金とライフ（Core）→ スロット（Core）→ 出目の効果・バッファー・スキル（Core）→ 戦闘マス（Core）→ ルート（Core）→ データ（マップ・出現・検証）→ 筐体 → 操作バー → 流れ（ルート・各マスの画面）→ 説明・早見表 → 文字あり版 → 文字チェックとマウス通し → 掃除と文書。各タスクで消す機能のテストは機能と一緒に消し、EditMode/PlayMode の件数の増減を tasks.md に書く。
- 途中は Game シーンが動かない期間ができる（Core を替えてから Runtime を替えるまで）。PlayMode テストのうち動かなくなるものは、そのタスクの結果に「一時的に失敗」と件数を書き、筐体・流れのタスクで直すか書き直す。Core のタスクは EditMode が全件通ることを完了条件にする。
- PlayMode の既存の知見（`SlotCabinet.RandomOverride`・`GuideOverlay.DisabledForTests`・実時間待ち・実機デバイスを止める）は新しいテストでも使う。`AlwaysMissRandom` は20パターンの「ハズレ」を選ぶ乱数に直す。

### 16.12 リスク
| リスク | 対策 |
| --- | --- |
| 作り直しが大きく、途中でゲームが通しで動かない期間が長い | Core を先に固め、Runtime は筐体 → 流れの順で早めに通す。各タスクの終わりに EditMode を全件通す |
