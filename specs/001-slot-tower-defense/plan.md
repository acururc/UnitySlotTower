## 2. 画面とカメラ（FR-001, D-11, D-15, D-39）

- 基準解像度は縦長 1440×1920（3:4＝12:16。2026-10-30 にユーザー依頼で 9:16 から変更）。PC の初期ウィンドウは 960×1280 のウィンドウモード。縦横比は 3:4 で固定し、余白は黒帯にする。
- 上部 60% が戦闘フィールド（2026-11-01 変更、旧 38%）。戦闘カメラの Viewport Rect で描き、斜め見下ろし（俯角 約55°）の固定カメラとする。
- 下部 40% がスロット筐体（操作バーを含む）。uGUI のキャンバスに、筐体フレーム、リール窓（3リール×3段）、ボタン、ランプ、クレジット表示（数字）を置く。高さが減るので、リール窓とボタンを詰めて配置する。
- 戦闘とスロットの間に帯状の「操作バー」を置く: 味方4種のアイコン（コスト・待ち時間・ストック数・強化段階を数字とゲージで表示）、ライフ、所持コイン、ステージ-ウェーブ番号、攻撃力アップ・攻撃速度アップの残り秒数、一時停止ボタン。

## 3. 操作割り当て（FR-002）

| 操作 | マウス | キーボード案 |
| --- | --- | --- |
| 召喚する味方を選ぶ | 操作バーのアイコンをクリック | 1〜4 |
| 配置マスを選ぶ | フィールドへドラッグ＆ドロップ | 矢印キーでカーソル移動、Enter で決定 |
| 向きを選ぶ | 配置後に上下左右へドラッグ（アークナイツ式） | 矢印キー、Enter で決定 / Esc で取り消し |
| 配置中の味方を選ぶ | クリック | Tab で順に選択 |
| 撤退 | 選択中の撤退アイコン | X |
| 強化 | 操作バーの強化アイコン（種類ごと） | Shift + 1〜4 |
| ベット＋レバー | レバー（またはベット/スタートボタン） | Space |
| リール停止（左・中・右） | 各ストップボタン | J / K / L |
| 一時停止 / 再開 | 一時停止ボタン | P または Esc（配置操作中でないとき） |
| 戦闘開始（▶、準備中だけ） | 操作バーの ▶ | Enter（配置操作中でないとき。T308） |
| リールのカスタム: マスを選ぶ | マスをクリック | 左右の矢印 |
| リールのカスタム: 図柄を変える | 選んだマスをクリックするたびに次の図柄 | 上下の矢印 / Space |
| リールのカスタム: 確定 | ✔（条件を満たすときだけ押せる） | Enter |

- ベットとレバーは1回の操作にまとめ、押した時点で固定掛け金を自動で投入する。所持コインが足りなければレバーは反応せず、コインのアイコンが点滅する（FR-040）。
- キー割り当ては1つの InputActionAsset にまとめ、後から変更しやすくする。キーコンフィグ画面は作らない。
- 配置操作の解釈（T208）: 選択（1〜5／アイコンを押す）→ マス選び → 向き選び → 確定で支払う。召喚できない味方は選べない。選択中の味方をもう一度選ぶと選択をやめる。マウスはアイコンを押してマスで離す（アイコンをクリックしてからマスをクリックしてもよい）。マウスでの向きは、マスを決めた直後からポインターの方向（上下左右、マスの中心から半マス以上）を向き、フィールドをクリックすると確定する。マスの中心付近をクリックするとマス選びに戻る（マウスだけでの取り消し。2026-10-30 ユーザー要望でドラッグ式から変更）。フィールド外（操作バーなど）のクリックは確定に使わない。Esc は向き選び→マス選び→選択なしの順に1段階戻す。矢印は押した瞬間に1マス（押し続けで繰り返さない）。新しい選択の向きは右から始め、カーソルは前回の位置を引き継ぐ。

## 4. 進行と画面遷移（FR-005, FR-010, FR-013〜016）

```text
Title（ロゴだけ文字可） → 難易度選択（設定1〜6の筐体プレート） → Game
Game: [リールのカスタム] → [S1-W1 準備] → [S1-W1 戦闘] → [S1-W2 準備（配置は残る）] → [S1-W2 戦闘・中ボス]
      → [S1 クリア: ライフボーナス加算・ストック化・ライフ回復] → [リールのカスタム] → [S2-W1 準備] … → [S3-W2 最終ボス撃破]
                                                     ↘ ライフ0 → リザルト（ゲームオーバー）
最終ボス撃破 → リザルト（クリア） → リトライ（同じ難易度で Game をやり直す）/ Title
```

- シーンは `Title`（難易度選択を含む）と `Game` の2つ。リールのカスタムとリザルトは Game 内のオーバーレイ。リトライは Game の再読み込みで初期化する（AC-004）。リトライではリール配列も既定に戻す（1プレイ通しのため）。
- 準備フェーズ（C-2）: 各ウェーブ開始時、敵が出る前に配置できる時間を設ける。制限時間はなく、開始ボタン（▶）で戦闘が始まる。準備中は召喚の待ち時間を無視する（C-3）。スロットも回せる。
- ステージ内のウェーブ終了時（W1）: 配置・HP・ライフはそのままで W2 の準備に入る。ライフボーナス・ストック化・ライフ回復はしない。
- ステージ終了時（W2）: 配置中の味方を種類ごとに数えて無料ストックに加算し、全員をフィールドから外す。ライフを満タンに戻し、残りライフ×係数のコインを加算する。続けてリールのカスタムを開き、確定すると次のステージの準備に入る。
- カスタム中は戦闘が進まず（敵はいない）、スロットも回せない。
- 無料ストックがある種類は、コインを使わずストックから配置する（ストックを先に消費）。
- 実装の解釈（T304）: 準備中の召喚は待ち時間で拒否されず、待ち時間も始めない（戦闘開始時はどの種類も待ち時間0）。戦闘中のストックからの配置はコインを使わないだけで、待ち時間は通常の召喚と同じにかかる。使わなかったストックは次のウェーブ以降に残る。ウェーブの終わりは「出現予定の敵がすべて出て、フィールドに敵がいない」とき。
- ライフ: 敵が1体ゴールに着くたびに、その敵の「ライフ減少量」だけ減る（中ボスは複数、最終ボスは全ライフを想定）。

## 5. ルールの詳細（承認済み要求の実装解釈）

### 味方（FR-020〜028）
- ステータス: 最大HP、攻撃力、防御力、攻撃間隔、攻撃範囲（向き基準のマス相対座標の集合）、ブロック数、配置マス種別、召喚コスト、待ち時間。
- ダメージ式（アークナイツ準拠）: `max(攻撃力 − 防御力, 攻撃力 × 0.05)`。
- 攻撃対象: 範囲内でゴールに最も近い敵。弓だけが空中敵を対象にできる。剣士とタンクはブロック中の敵を優先する。
- ヒーラー: 範囲内で HP 割合が最も低い味方（満タンだけなら回復しない）。
- 役割は `units.csv` の `role`（`melee` 近距離・`ranged` 遠距離〔空中も狙える〕・`heal`）で持つ。回復量は（強化後の）攻撃力で、最大HPを超えない。味方は `tank`/`sword`/`archer`/`healer` の4種（2026-11-01 にバッファー `buffer`・役割 `buff`・列 `buff_rate` を廃止）。
- スロットの効果（D-45）: 攻撃力アップ・攻撃速度アップは戦闘全体の倍率として持ち、効果中は配置中の味方と効果中に新しく置いた味方の全員に効く。攻撃力アップは攻撃と回復の両方に掛け、攻撃速度アップは攻撃間隔を倍率で割る。残り時間は戦闘のステップで数えるので、準備中・一時停止中・カスタム中は減らず、ステージをまたいで持ち越す。効果中に再成立したら残り時間に持続時間を足す。全体HP回復は成立した瞬間に配置中の味方全員へ最大HPの割合を足す（最大HPまで、四捨五入）。
- 対象の判定: 敵は中心が入っているマスで範囲に入る。ブロック中の敵は範囲に関係なく優先して狙う。同じ条件なら先に出た敵、回復は先に配置した味方。攻撃・回復の対象がないあいだは攻撃間隔を消費しない。
- 1ステップの順序: 出現 → 移動（ゴール到着でライフ減少） → 敵の攻撃 → HP0の味方の消滅（ブロックしていた敵は再び進む） → 味方の行動 → HP0の敵の消滅（ブロックの空きを戻し、ドロップを抽選）。ライフは0で止まり、ゲームオーバーになったら戦闘は進まない。
- 強化: 種類ごとに段階 1〜5。段階ごとの倍率（HP・攻撃・防御）と費用をテーブルで持つ。強化した瞬間、配置中の同種全個体のステータスを再計算する（最大HPが増えた分は現在HPにも加算）。
- 撤退: 個体を消し、`召喚コスト × 返還率` を切り捨てで返す。ストックから出した個体も、その種類の召喚コストを基準に返す（C-3）。
- 配置上限: フィールド上の味方の総数。ストックからの配置も上限に数える（C-3）。

### 敵（FR-030〜033）
- ステータス: HP、攻撃力、防御力、攻撃間隔、移動速度、射程、空中フラグ、ブロック消費数（ボスは2以上）、ライフ減少量、ドロップ確率、ドロップ量（最小〜最大）。
- 近距離雑魚: ブロックされると、ブロックした味方を攻撃する。遠距離雑魚: 移動しながら、射程内の味方（高台を含む）を攻撃する。ブロックされると停止する。空中雑魚: ブロックされず、空中経路を進み、射程内の味方を攻撃する。
- ブロックの位置: 地上の敵は、ブロックの空きが消費以上ある味方のマスの手前の境界（マス中心の 0.5 マス手前）で止まる。既にそのマスの中に居れば、その場で止まる（2026-10-30 ユーザー確認）。
- ドロップ: 味方に倒されたときだけ、ドロップ確率で当たれば量を最小〜最大（両端を含む一様）で決める。ゴールに着いた敵は落とさない。乱数は戦闘に注入する（シード固定で再現できる）。
- 中ボス・最終ボス: 高HP・高ブロック消費。中ボスは固有の行動を持たず、ステータスだけが強い。最終ボスはステータスに加えて範囲攻撃を持つ（2026-10-30 ユーザー決定）。
- 範囲攻撃（T306）: `enemies.csv` の `area_atk`（0 なら持たない）・`area_radius`（マス）・`area_interval`（秒）。出現から1間隔後に、敵の位置から半径内にマス中心がある味方全員を `area_atk` で攻撃する（ダメージ式は通常と同じ）。半径内に味方がいないあいだは間隔を消費しない。通常の攻撃とは別に行う。
- クリア: 最終ボスを倒しても、残りの敵を全滅させるまではクリアにしない（最終ウェーブの終了＝クリア。2026-10-30 ユーザー決定）。最終ボスはゴールに着くと全ライフを失わせる。

### スロット（FR-040〜048、2026-11-01 改訂）
- 構成: 3リール × 12コマ（`slot_rules.csv` の `reel_length`）、3段表示。3本とも同じ配列。有効ラインは中段の1本。固定掛け金は 3枚。
- 図柄: 攻撃力アップ（`atk`）・攻撃速度アップ（`speed`）・全体HP回復（`heal`）・コイン（`coin`）・7（`seven`）・BAR（`bar`）。
- 抽選（D-43）: レバーオン時に、設定ごとのハズレ率（`slot_settings.csv`）で当たり/ハズレを決める。当たりなら、配列での各図柄のマス数に比例した重みで揃う図柄を1つ決める。
- 出目（D-44）: ストップボタンを押した位置から、結果に合う最初の停止位置まで進めて止める。当たりは各リールの中段に結果の図柄を止める（全図柄が配列にあるので必ず止められる。最大 `reel_length − 1` コマ滑る）。ハズレは押した位置で止めるが、最後に止めるリールで中段が3つ揃ってしまう場合は揃わない最初の位置まで進める。押す順は自由。押した位置は結果を変えない。
- 払い出しと効果: コイン揃いは `coin_payout` 枚を払う。攻撃力アップ・攻撃速度アップ・全体HP回復は戦闘へ効果を渡す（味方の節）。効果の図柄は払い出しなし。
- ボーナス（D-33/D-40）: 7揃いで BIG、BAR揃いで REG。ボーナス中は `big_games`/`reg_games` ゲームのあいだ掛け金なしでレバーを引け、毎ゲーム コインが揃って `big_payout`/`reg_payout` 枚を払う（ハズレ抽選なし、出目はコイン揃い）。消化し終えると通常に戻る。
- ウェイト（初期値 2.0 秒、前のレバーオンから数え、待ち中に押したレバーは時間が来たら回す。回転中のレバーは無視）は従来どおり。
- リールのカスタム（D-46〜D-49）: Core に `ReelLayout`（`reel_length` マスの図柄列）。7・BAR はちょうど1つ、ほかの4図柄は各1つ以上、マス数が `reel_length` と一致すれば確定できる。画面ではマスごとに6図柄から選べ（7・BAR の位置も動かせる）、条件を満たさないあいだは ✔ が押せず、足りない・多すぎる図柄のアイコンを赤く点滅させる。並び順は見た目だけで確率に影響しない。表示: ハズレ率・当たり率（現在の設定の値）と当たり時の各図柄の確率（マス数 ÷ 総マス数）。% は小数1桁に四捨五入。既定配列は `slot_default_reel.csv`。
- 筐体の仮表示: ボーナス中ランプと残りゲーム数、クレジット、直前の払い出し。効果の残り秒数は操作バー（2章）。
- 廃止（2026-11-01）: 確変、先バレ（ランプと音）、リプレイ・ベル・スイカ・チェリー、内部抽選表、リール制御（引き込み・蹴飛ばし）、フラグ持ち越し、5ライン、機械割の目標と理論計算。

## 6. データテーブル（FR-050, D-32, C-1）

数値の正本は CSV。配置は `Assets/UnitySlotTower/Data/Tables/`。Excel などで編集し、保存形式は「CSV UTF-8（コンマ区切り）」とする。列名は英数字（例: `id,max_hp,atk`）で、1行目を見出しにする。

| ファイル | 主な内容 |
| --- | --- |
| `game_config.csv` | キーと値: 初期コイン、掛け金、ライフ、ライフボーナス係数、配置上限、撤退返還率 |
| `units.csv` | 味方4種のステータス、配置マス種別、ブロック数、コスト、待ち時間、役割 |
| `unit_ranges.csv` | 味方ごとの攻撃範囲（右向き基準のマス相対座標。向きに応じて回転） |
| `unit_upgrades.csv` | 種類×段階ごとの倍率（HP・攻撃・防御）と費用 |
| `enemies.csv` | 敵5種のステータス、空中フラグ、ブロック消費、ライフ減少量、ドロップ確率と量 |
| `maps/s1.csv` 〜 `s3.csv` | ステージごとのグリッドを表で描く（1セル＝1マス。`G`地上 `H`高台 `X`通行不可 `S1`出現口 `E`ゴール など） |
| `map_paths.csv` | マップ・経路IDごとのマスの並び（地上経路と空中経路） |
| `waves.csv` | ステージ番号、ウェーブ番号（1〜2）、出現時刻、敵の種類、出現口、経路、ボスかどうか |
| `slot_settings.csv` | 設定1〜6のハズレ率 |
| `slot_rules.csv` | キーと値: リールのマス数、掛け金、ウェイト、コインの払い出し、BIG/REG のゲーム数と1ゲームの払い出し、攻撃力アップ・攻撃速度アップの倍率と秒数、全体HP回復の割合 |
| `slot_default_reel.csv` | 既定のリール配列（`reel_length` マスの図柄 id） |

- 読み込み: CSV は TextAsset として参照し、コア層のパーサーで読み取り専用データに変換する。プレハブ・アイコン・音などの「数値でない参照」は、CSV の `id` をキーにした ScriptableObject（`PresentationCatalog`）にまとめる。
- 検証: 全CSVを読み込み、型・範囲・ID参照・確率（0〜1）・既定のリール配列が D-46 の条件を満たすこと・マップの経路の連続性を確かめる EditMode テストを置く。CSV を壊すとテストが失敗し、エラーにファイル名・行・列を出す。
- 試し方: Editor のメニューから、実行中に CSV を再読み込みできるようにする（次のウェーブ・次のゲームから反映）。
- 廃止（2026-11-01）: `slot_reels.csv`・`slot_payouts.csv`・`slot_probabilities.csv`・`slot_premonition.csv`、`maps/w1〜w5.csv`、理論機械割の Editor ツール（`SlotTheory`・`SlotTheoryReport`）。

## 7. マップとウェーブ（FR-010）

- グリッドは 9列×6行を基本にする。戦闘が上部60%に広がるので、T317 の画像確認でマスの大きさとカメラを合わせる（必要ならマップを広げる。データだけで変えられる）。
- 既存のマップを流用する: S1 ← 旧 w2（S字の一本道）、S2 ← 旧 w4（出現口2つ＋空中路）、S3 ← 旧 w5（地上路2本＋空中路）。
- S1: W1 近距離雑魚中心、W2 遠距離雑魚が加わり最後に中ボス。S2: W1 空中雑魚が初登場（弓の必要性）、W2 分岐と混成で最後に中ボス。S3: W1 全種混成、W2 全種混成で最後に最終ボス。
- 1ウェーブの長さは 2〜3分を目安にする（全体 12〜18分）。具体的な敵の数とタイミングは T309 でプレイしながら決める。

## 8. 文字を使わない UI（FR-003, FR-004）

- フォントは数字（0-9）・小数点（カスタム画面の%用、T316）と記号（+ − × / %）だけを含む TextMeshPro フォントアセットを使う。それ以外の文字はそもそも表示できない作りにする。
- 自動チェック: Title 以外のシーンとプレハブの全テキスト部品を走査し、数字・記号以外の文字があれば失敗する EditMode テストを用意する（AC-001 を補う）。
- 説明の見せ方: 各要素を初めて使う場面（例: W1 開始時の召喚、初めてのボーナス）で画面を薄暗くし、対象を光らせて矢印と手のアイコンのアニメで操作を示す。一時停止中は「?」アイコンから、図柄＝効果（倍率・秒数・払い出し）の早見表と現在のハズレ率・各図柄の確率、味方の能力（範囲図・数値）を見られる。
- 状態は色と形で区別する: 召喚可能（明るい）、コスト不足（暗い＋コインアイコン赤）、待ち時間中（円形ゲージ）、ストックあり（数字バッジ）。

## 13. 2026-11-01 仕様変更の移行方針

- 消すもの: Core/Slot の `SlotProbabilities`・`SlotReelControl`・`SlotPremonition`・`SlotTheory`・`SlotPayouts`・`SlotReels`・`SlotLines`（1ライン化で不要なら）と対応テスト、Editor `Slot/SlotTheoryReport`、旧スロット CSV、`maps/w1〜w5.csv`、味方 `buffer` の行と `buff` 処理、筐体の先バレ・確変・リプレイのランプと先バレ音。消す前に参照を検索し、シーン・アセットの参照切れがないことを Console で確かめる。
- 作り直すもの: `SlotSymbol`（6図柄）、`SlotRules`（新キー）、`SlotMachine`（ハズレ抽選・配列比率・出目・ボーナス・効果の通知）、`WaveSchedule`/`WaveRun`（ステージ×ウェーブ）、`PortraitLayout`（6:4）、`SlotCabinet`/`SlotReelView`、操作バー（4種・効果の残り時間・S-W 表示）。
- 新しく作るもの: Core `ReelLayout`（検証と確率）、`SlotSettings`、`SlotEffects`（戦闘側の倍率と残り時間）、Runtime のカスタム画面、Editor の組み立てメニュー。
- 入力: InputActionAsset の `5`・`Shift+5` のバインドを外す。カスタム画面のキーボード操作は既存の `Cursor`・`Confirm`・`Lever`（Space）を使い、マウスは UI のボタン（T316。Enter・Space が UI の Submit と重なるため EventSystem のナビゲーションは使わない）。
- 順序: 戦闘側（バッファー廃止 → ステージ化）→ スロットの Core → 効果の結合 → 筐体表示 → カスタム画面 → 画面比率 → データ検証と文書。各タスクの終わりに EditMode/PlayMode を実行し、件数を tasks.md に残す。
