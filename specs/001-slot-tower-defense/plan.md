## 2. 画面とカメラ（FR-001, D-11, D-15, D-39, D-71）

- 基準解像度は縦長 1440×1920（3:4）。PC の初期ウィンドウは 960×1280 のウィンドウモード。縦横比は 3:4 で固定し、余白は黒帯にする（`PortraitLayout`）。
- 上部 50% が戦闘の領域（D-87）。上端の帯はその 10%（96 px、`PortraitLayout.TopBandRatio`）で、戦闘カメラは残りの 1440×864 px（`PortraitLayout.BattleView`）を映す（18.4）。カメラは正面から斜めに見下ろす固定カメラで、戦闘マスごとに Core `BattleCameraFit` がマップの列数・行数から距離と注視点を決める（俯角 55°〔T357、ユーザー確定〕）。左右の余白は 0 で、手前の角は高台の上面までを横幅に収め、空中の高さは上下だけで収める（空中の敵は手前の角でわずかに切れてよい）。帯を除いても横の画角は変えない。
- 下部 50% のうち 37.5〜50% が操作バー、0〜37.5% がスロット筐体（uGUI）。割合は Core `PortraitLayout`（`BattleHeightRatio`・`SlotAreaTop`）の1か所で持つ。筐体はリール窓（3リール×3段）・レバー・コインの数（回数固定の戦闘ではコインのアイコンの代わりに回数固定の印と残り回数）。ストップボタン・ボーナスランプ・払い出しはない（16.8）。揃ったときは中段を光らせ、光の玉が効果の行き先へ飛ぶ（`SlotAlignEffect`、17.6）。
- 操作バーは味方4種の札とスキルゲージ。札には盤上の駒と同じ形の影絵・¥のコスト・待ち時間・ストック数・強化段階と強化ボタン・ブロック数（壁と赤い三角、0 は赤い ×）を出す。札の右上はスキルの絵、その下は5点のゲージ（満タンで点滅しクリックで発動）。ライフ、所持金（¥）、残りの敵数、攻撃力倍率と所持金倍率（`×1.2` など、倍率なしは薄く `×1.0`）、倍速（`×1`〜`×3`）、一時停止は上端の帯に置く（18.4・18.5）。コインの枚数は筐体のまま。攻撃範囲は選んだ味方1体だけに出す。
- 戦闘マスの始めは `BattleIntroView` で、暗い背景にマスの種類のアイコン（文字あり版はマスの名前）→ 背景が盤面に変わる → アイコンが消える。開始の演出中は全経路に流れる矢印を出す。戦闘中は群れの出始めだけ、その経路を示す（19.3）。出口には赤い枠を常に置き、敵が出る瞬間は 0.3 秒光らせる。本拠地に着くと本拠地と帯のライフを 0.5 秒赤く光らせ、ライフの数字を一瞬大きくする。`ScreenEdgeFlash` は画面の縁を0.45秒赤く光らせる。光っている間も操作できる。
- 戦闘以外の画面は2D: ルート画面は操作バーの下端から上（戦闘フィールドと操作バー）を覆うオーバーレイで、下の筐体をルート選びに使う。ショップ・回復は筐体も覆う全画面オーバーレイ（16.7）。

## 3. 操作割り当て（FR-002）

（2026-11-06、D-55）マウスだけで遊べることが要件。キーボードは要件外で、下の表のキーボード列は既存の実装の記録（保証もテストの追加もしない）。新しい操作（スキル・ルート・ショップ）にキーは足さない。

| 操作 | マウス | キーボード（記録） |
| --- | --- | --- |
| 召喚する味方を選ぶ | 操作バーのアイコンをクリック | 1〜4 |
| 配置マスを選ぶ | フィールドへドラッグ＆ドロップ（またはアイコン→マスのクリック） | 矢印キーでカーソル移動、Enter で決定 |
| 向きを選ぶ | 配置直後のポインターの方向、フィールドのクリックで確定 | 矢印キー、Enter で決定 / Esc で取り消し |
| 配置中の味方を選ぶ | クリック | Tab で順に選択 |
| 撤退 | 選んだ味方の詳細の板の撤退ボタン（戻る額つき） | X |
| 強化 | 札の強化アイコン（種類ごと） | Shift + 1〜4 |
| スキルの発動 / 説明 | 戦闘中は満タンのゲージをクリックして発動。一時停止中はゲージで説明を開く | なし |
| ベット＋レバー（戦闘） | 筐体のレバー | Space |
| ルートの行き先を選ぶ（リールは自動で回る） | 行き先のあるリールかその上の矢印をクリック | なし |
| 倍速（×1→×2→×3→×1） | 一時停止の隣の倍速ボタン | なし |
| ショップの購入・両替、◀ で戻る | 品の札・両替のボタン・◀ | なし |
| 一時停止 / 再開 | 一時停止ボタン | P または Esc（配置操作中でないとき） |
| 早見表を開く / 閉じる（T404） | 一時停止中、上端の帯で倍速ボタンと入れ替わる「?」、閉じるのは ◀ | ?（/）キー。一時停止していなければ一時停止して開く。再開すると閉じる |
| タイトルへ戻る | 一時停止中、「?」の左の家を押し、確認の板で ✔ を押す。× で一時停止に戻る | Esc で確認を閉じる |

- 入力アクションは `InputSystem_Actions.inputactions` の `SlotTower` マップ（`SelectUnit1〜4`・`Upgrade1〜4`・`Cursor`・`Confirm`・`Cancel`・`CycleUnit`・`Retreat`・`Lever`・`Pause`・`Help`・`Point`・`Press`）。リールの停止（`StopLeft` など）と `ClearCell` は機能ごと削除した（T348）。Shift+数字は `SelectUnit` と `Upgrade` の両方に反応しうるので、Shift 中は `SelectUnit` を無視する。キーコンフィグ画面は作らない。
- ベットとレバーは1回の操作にまとめ、押した時点で掛け金（`bet`）をコインから払う。足りなければ回らず、コインのアイコン（回数固定中はその印）が点滅する（FR-040）。回転中のレバーは無視する。
- 配置操作の解釈（T208）: 選択（アイコンを押す）→ マス選び → 向き選び → 確定で所持金を払う。召喚できない味方は選べない。選択中の味方をもう一度選ぶと選択をやめる。マウスはアイコンを押してマスで離す（アイコンをクリックしてからマスをクリックしてもよい）。向きはマスを決めた直後からポインターの方向（上下左右、マスの中心から半マス以上）を向き、フィールドをクリックすると確定する。マスの中心付近をクリックするとマス選びに戻る（マウスだけでの取り消し）。フィールド外（操作バーなど）のクリックは確定に使わない。Esc は向き選び→マス選び→選択なしの順に1段階戻す（配置操作中でなければ一時停止）。新しい選択の向きは右から始める。

## 4. 進行と画面遷移（FR-005, FR-010, FR-013〜018）

```text
Title（ロゴだけ文字可。隠しボタンで文字あり版） → 難易度選択（設定1〜6の筐体プレート） → Game
Game: ルート画面（1階 = 最初の戦闘マスだけ） → 戦闘マス [開始の演出 → 1ウェーブ → 勝利の帯] → ルート画面
      → 回るリールで行き先を選ぶ → 移動のアニメ → 戦闘 / 強敵 / ショップ / 回復 → ルート画面 → … → 最上階のボス（最終ボス）
                                    ↘ ライフ0 → リザルト（ゲームオーバー）
ボスマスの終了 → リザルト（クリア） → リトライ（Game を読み直し、新しいシードでルートから作り直す）/ Title
```

- シーンは `Title`（難易度選択を含む）と `Game` の2つ。Game の `RunController` が `RunState` とルートを作り、ルート → 各マス → ルートを回す。戦闘マスは `BattleController` に任せ、戦闘以外は Runtime の画面の登録表（`NodeScreen`）から種類ごとの画面を開く。リザルトは Game 内のオーバーレイで、結果のアイコン（クリア＝王冠、ゲームオーバー＝×）・到達した階・所持金・コインを出し、▶ でリトライ・◀ でタイトル（T350d）。
- 戦闘マス（D-78・D-79、17.2）: 1ウェーブだけ。準備フェーズと ▶ はなく、入ると開始の演出（`intro_seconds`）のあいだ戦闘の時間を止めて召喚・撤退・強化・スロット・スキルを拒否し、終わると戦闘が始まる。段階は `BattleNodeRun` の `Intro` → `Fighting` → 終了。
- 戦闘マスの終了: 最後の敵が消えたら、盤面中央に勝利のアイコンの暗い帯（文字あり版は「戦闘終了」）を約1.2秒出す。帯の間は時間を止めて入力を受けず、その後でルート・リザルトへ進む（18.7）。配置中の味方は種類ごとに数えて無料ストックに加え、全員をフィールドから外す。報酬（`reward_money`・`reward_coins`）を足し、バー・コインの倍率は捨てる。ライフは回復しない（回復はショップではなく回復マスで）。ゲームオーバーなら報酬なし。
- 無料ストックがある種類は、所持金を使わずストックから配置する（ストックを先に消費）。
- 実装の解釈: ストックからの配置は所持金を使わず、待ち時間を始めず、待ち時間中でも出せる（17.2）。使わなかったストックは次の戦闘マス以降に残る。ウェーブの終わりは「出現予定の敵がすべて出て、フィールドに敵がいない」とき。
- ライフ（`RunState`）: 敵が1体ゴールに着くたびに、その敵の「ライフ減少量」だけ減る（中ボスは複数、最終ボスは全ライフを想定）。0で止まりゲームオーバー。
- ルート選び中・ショップや回復の画面中は戦闘の入力（配置・スキル）を受け付けない。画面中と移動のアニメ中はレバーも止める（`SlotCabinet.HeldByScreen`）。
- 倍速とスロー（18.1・18.7）: `BattleController.BattleSpeed` は1〜3で、`BeginNode` で毎回1に戻す。`Time.timeScale` を書くのは `ApplyTimeScale` だけ。一時停止・勝利の帯は 0 → 戦闘中の配置操作（札を選んでから向きを決めるかやめるまで）は `placement_time_scale`（0.2、倍速に関係なく同じ）→ それ以外の戦闘中は倍率 → 開始の演出・ルートなどは 1。説明中は従来どおり戦闘のステップだけを止める。

## 5. ルールの詳細（承認済み要求の実装解釈）

### 味方（FR-020〜029）
- ステータス: 最大HP、攻撃力、防御力、攻撃間隔、攻撃範囲（向き基準のマス相対座標の集合）、ブロック数、配置マス種別、召喚コスト（所持金）、待ち時間。
- ダメージ式（アークナイツ準拠）: `max(攻撃力 − 防御力, 攻撃力 × 0.05)`。敵を遠距離職が攻撃するときだけ、防御・最低ダメージ計算の後に敵の `ranged_damage_rate`（既定 1）を掛けて四捨五入する。スキルの攻撃にも同じ耐性を適用する（18.2）。
- 攻撃対象: 範囲内でゴールに最も近い敵。弓だけが空中敵を対象にできる。剣士とタンクはブロック中の敵を優先する。遠距離（弓）は空中の敵が先で、同じ種類の中ではゴールまでの残りの道のりが短い順（D-81、17.4）。
- 役割は `units.csv` の `role`（`melee` 近距離・`ranged` 遠距離〔空中も狙える〕・`buff`）。味方は `tank`/`sword`/`archer`/`buffer` の4種。弓は atk 240・attack_interval 0.9秒、強化の伸びをほかの職より低くする。弓2体で空中の群れは倒せても地上の群れは倒しきれないことを固定配置の EditMode シミュレーションで確かめる（仮の値、18.2）。
- バッファー（16.5）: 攻撃しない。範囲内の自分以外の味方の攻撃力に、効いているバッファーのうち最大の `buff_rate` を1つだけ掛ける（重ねがけしない）。強化は HP・防御に効き、倍率は変わらない。
- 攻撃力の掛け順: 基礎 × 強化（四捨五入）× バッファー × バー × スキルを最後に四捨五入。攻撃速度はスキルだけが変える（16.4）。
- スキル（FR-029、16.4）: 色ごとのゲージ（`RunState`、戦闘マスをまたいで残る）が満タンで、配置中のその職全員に効果を付ける。発動は満タン・その職が1体以上・戦闘中（開始の演出の後）・一時停止していないときだけで、拒否なら何も変えない。効果時間は戦闘ステップで減り、発動後に置いた個体には付かない。
- 対象の判定: 敵は中心が入っているマスで範囲に入る。ブロック中の敵は範囲に関係なく優先して狙う。同じ条件なら先に出た敵。攻撃の対象がないあいだは攻撃間隔を消費しない。
- 1ステップの順序: 出現 → 移動（ゴール到着でライフ減少） → 敵の攻撃 → HP0の味方の消滅（ブロックしていた敵は再び進む） → 味方の行動 → HP0の敵の消滅（ブロックの空きを戻し、ドロップを抽選）→ スキルの効果時間を減らす。ゲームオーバーになったら戦闘は進まない。
- 強化: 種類ごとに段階 1〜5。段階ごとの倍率（HP・攻撃・防御）と費用（所持金）をテーブルで持ち、`RunState` が持つのでゲーム中ずっと残る。強化した瞬間、配置中の同種全個体のステータスを再計算する（最大HPが増えた分は現在HPにも加算）。
- 撤退: 個体を消し、`召喚コスト × 返還率` を切り捨てで所持金に返す。ストックから出した個体も、その種類の召喚コストを基準に返す（C-3）。撤退の説明の表示中は全額を返す（D-56）。
- 配置上限: フィールド上の味方の総数。ストックからの配置も上限に数える（C-3）。

### 敵（FR-030〜033）
- ステータス: HP、攻撃力、防御力、攻撃間隔、移動速度、射程、空中フラグ、ブロック消費数（ボス・重装は2以上）、ライフ減少量、ドロップ（コインと所持金のそれぞれの確率と量）、範囲攻撃、遠距離ダメージ倍率（`ranged_damage_rate`）。
- 重装（`heavy`、18.2）: 地上の近距離。HP2200・def180・block_cost2・遠距離倍率0.4（仮）で、通常・強敵・ボスの群れに混ぜる。最初の戦闘には出さない。`BattleActorsView` は `ranged_damage_rate` < 1 の敵に盾を付ける。
- 近距離雑魚: ブロックされると、ブロックした味方を攻撃する。遠距離雑魚: 移動しながら、射程内の味方（高台を含む）を攻撃する。ブロックされると停止する。空中雑魚: ブロックされず、空中経路を進み、射程内の味方を攻撃する。弓と射程のある敵の通常攻撃では、攻撃時にダメージを与えた後、プールの矢・弾を相手まで飛ばす（表示のみ、19.6）。
- ブロックの位置: 地上の敵は、ブロックの空きが消費以上ある味方のマスの手前の境界（マス中心の 0.5 マス手前）で止まる。既にそのマスの中に居れば、その場で止まる。
- ドロップ（D-30・D-67）: 味方に倒されたときだけ1回抽選する。`[0, coin_rate)` ならコイン、`[coin_rate, coin_rate + money_rate)` なら所持金で、量は最小〜最大（両端を含む一様）。所持金にはコインの倍率を掛けて四捨五入する。和が1を超える行は読み込みエラー。ゴールに着いた敵は落とさない。
- 中ボス・最終ボス: 高HP・高ブロック消費。中ボスはステータスだけが強い（強敵マス）。最終ボスはステータスに加えて範囲攻撃を持つ（ボスマス）。
- 範囲攻撃（T306）: `enemies.csv` の `area_atk`（0 なら持たない）・`area_radius`（マス）・`area_interval`（秒）。出現から1間隔後に、敵の位置から半径内にマス中心がある味方全員を `area_atk` で攻撃する（ダメージ式は通常と同じ）。半径内に味方がいないあいだは間隔を消費しない。
- クリア: 最終ボスを倒しても、残りの敵を全滅させるまではクリアにしない（ボスマスの終了＝クリア）。最終ボスはゴールに着くと全ライフを失わせる。

### スロット（FR-040〜045、詳細は 16.3）
- 構成: 3リール × 6マス（`slot_reels.csv`、各リールに6図柄が1つずつ、3本とも違う並び）、3段表示。掛け金は `game_config` の `bet`（2枚、D-77）。
- 図柄: 色7（赤・青・緑・黄）・バー・コインの6種。出目は図柄の揃いかハズレ。
- 抽選（D-60）: レバーの時点で、難易度の設定の20パターン（`slot_patterns.csv`）から1つを一様に選ぶ。揃いはその図柄が中段に来る停止位置、ハズレはどの段も揃わない組み合わせから一様に選ぶ。並びは「どの図柄を中段に揃えても上段・下段が揃わない」ことをデータ検証で確かめる。
- 停止: リールは自動で左から止まり（`first_stop_seconds`・`stop_interval_seconds`）、最後のリールが止まった時点で `Settle` して効果を渡す。回転中のレバーは無視する。
- 効果（FR-042、16.4）: 色7 → その色のスキルゲージ +1（満タンで止まる）。バー → その戦闘マスの攻撃力倍率 +`bar_step`（上限 `bar_cap`）。コイン → その戦闘マスの所持金ドロップ倍率（1回目 ×1.1、上限 ×1.5）。払い出しはない。
- 回数固定（D-68）: `encounters.csv` の `fixed_spins` が正の戦闘マスでは、その回数だけコインを使わずに回せる（最初の戦闘は6回）。
- ルート選び（D-75・D-90、16.7・17.8）: 同じ筐体をルート選びのモードで使い、コインも回数固定も減らさず、図柄の効果もない。ルート画面に入るとリールが自動で回り（レバーは何もしない）、選んだリールが先に止まり、残りは左から 0.15 秒間隔で止まる。
- 廃止（2026-11-14）: ハズレ率と配列比率の抽選、目押しとストップボタン、BIG/REG、払い出し、序盤の救済、ウェイト、リールのカスタム（ロック配置）、攻撃力・攻撃速度アップ、全体HP回復。

## 7. マップとウェーブ（FR-010, FR-018）

- マップは横9〜10×縦4〜5マス（検証で確かめる）。`first`（10×5、中3行が出現口からゴールまでまっすぐな地上、上下が高台）、通常 `battle_a`（S字1本＋空中）・`battle_b`（出現口2つが合流＋空中）・`battle_c`（Uターン＋空中）・`battle_d`（9×5、左右2つの出口から中央の本拠地へ、途中で合流しない）・`battle_e`（10×5、上下に分かれた2つの出口と2つの本拠地）、強敵 `elite_a`（上下から合流＋空中）、ボス `boss_a`（出現口3つ＋空中）。強敵・ボスのマップは専用。
- 本拠地は複数でもよい。各経路の終点を本拠地にし、どちらに敵が着いても共通のライフから `life_damage` を引く。`battle_d`・`battle_e` の空中路は出口1から各1本。全経路の連続性と本拠地で終わること、全出口・本拠地がカメラに収まることを EditMode で確かめる（18.3）。
- 戦闘マスに入ったとき、`encounters.csv` から種類と階が合う行を集める。1階は `first`、最上階は `boss`、間の階は通常と強敵（`elite_min_floor` 以上）。別のマップが候補にあれば直前と同じマップを除き、`EncounterTable.Pick` が残った行の `weight` に比例して選ぶ。通常マップの重みは `battle_a`〜`battle_c` が各7、`battle_d`・`battle_e` が各26（19.1）。
- 1つの戦闘マスは1ウェーブ（D-78）。敵は3〜5体の群れで出る（D-80）。強敵マスに中ボス、ボスマスに最終ボス。最初・通常の戦闘に中ボスはいない。最初の戦闘は中央のレーンだけを使い、重装を出さない（検証器で確かめる）。
- ルート（D-88、17.7）: 3列の格子。1階は中央の `first`、2階〜ボスの2つ前の階は各3マス、ボスの直前の階は回復3つ、最上階はボス。つながりは列の差 −1〜+1。
- ルートの線（18.6）: 今のマスから行ける線は白で太く（`lineWidth` の 1.8 倍）、通ってきた道は金で細く（0.6 倍）、それ以外は不透明度 0.15。今からたどれない上の階のマスは不透明度 0.22、通ったマスの右下には金の丸。移動中は選んだ線だけを太く明るくする（見た目の値は仮）。
- 出現の数とタイミングは仮。1ゲームの長さと難しさは T399 の通しプレイで調整する。

## 8. 文字を使わない UI（FR-003, FR-004, FR-006）

- 文字なし版のフォントは数字（0-9）・小数点と記号（+ − × / % ?）だけを含む TextMeshPro フォントアセット（`NumericOnly SDF`）。それ以外の文字は表示できない作りにする。
- 自動チェック: シーン（Title はロゴ以外）とプレハブの全テキスト部品を走査し、数字・記号以外の文字があるか数字専用フォント以外を使っていれば失敗する EditMode テスト（`TextAudit`）。実行中にコードが入れる文字は、各画面（タイトル・難易度・戦闘・早見表・説明・ルート・ショップ・回復・リザルト）を開いて調べる PlayMode テスト（`ScreenTextTests`）で確かめる。どちらも文字あり版のラベル（`TextModeLabel`）は対象外にし、文字なし版で描かれないことを確かめる。
- 文字あり版（FR-006、16.9）: タイトルのロゴ右下の隠しボタンで切り替え（起動ごとに文字なし）。文言は `ui_texts.csv`、フォントは Noto Sans JP の静的アセット（`TextMode SDF`）。ラベルは `TextModeSetup`、配置は `Runtime/Ui/TextModeLayout`（部品ごとに両方の版の値、値は `TextModeLayoutSetup`）で切り替える（T359）。ラベルの地は不透明な地（札・帯・区画・筐体など）の上なら付けず、盤面など透けた所だけ `UiPanel` を付ける（18.4）。開始と勝利の文言は `node_*`・`battle_end`、スキルの説明は `skill_<職>`・`skill_help_off`・`skill_help_on` を表から引く。読みやすさ（36 以上・画面内・省略なし・重ならない）は PlayMode `TextModeTests` が全画面で確かめる。
- UI の土台（18.4）: 共通の色は `Runtime/Ui/UiStyle`、角を切った地と縁は `UiPanel`、既存の Image と Button の押す範囲を残して最初の子 `Skin` に見た目を移す部品は `UiSkin`。タイトル・難易度・ルート・ショップ・回復・リザルト・早見表も同じ土台を使う。画面の地・帯・札・区画を色分けし、進むボタンは黄色、説明の「?」は青にする。
- 選んだ味方の詳細（`UnitDetailPanel`）: 盤面と札の間に職の絵・強化段階・体力（バーと数字）・攻撃力・ブロック数・スキルの絵・撤退ボタン（戻る額）を出す。盤上の味方をもう一度押すか空いた所を押すと閉じる。撤退ボタンの出し入れは板、押下の接続は `OperationBarStatus` が行う。強化は札に残す（18.4 のユーザー回答）。
- ブロックとスキル（18.5）: 壁と赤い三角＋数（0 は赤い ×）を札・詳細・向き選び中の予定マスの上（`PlacementBlockBadge`）に出す。`SkillPictures` が効果の絵を図形で作る（赤＝星形、青＝▶▶、緑＝上向き矢印、黄＝盾）。一時停止中にゲージを押すと `SkillHelpPanel` を開き、`DemoLane` の2本の道でスキルなし・スキル中を比べる。黄は止める数、赤は被ダメージ、青は攻撃間隔、緑は近接職の攻撃力の違いを見せる。どこかを押すか一時停止を解くと閉じる。
- 状態は色と形で区別する: 置ける札はそのまま、所持金不足は暗く値段を赤、待ち時間中は暗い赤と残り秒の円、無料ストックは数のバッジ、スキルゲージ満タンは点滅。買えない品・足りない両替は暗い。盤上の味方と敵の足元に細い体力バー（味方は青・敵は赤）、ゲージが満タンの職の味方の頭上に黄色のひし形。命中の光は `BattlePresentationTiming.HitFlash`（0.12秒）にそろえる（18.4・18.7）。
- 文字なし説明（T403・T351、16.10）: 1回のプレイの中で題目ごとに一度だけ出す（保存しない）。説明中は戦闘の時間だけを止め（`BattleController.IsHeldByGuide`。スロットと操作は動く）、対象を問わず、その種類の操作で次へ進む。暗幕はクリックを通す。光る枠の右上の × を押すと `GuideObservation.Dismissed` で今の説明を閉じる（19.7）。進行の判定は Core `GuideSequence`、表示は Runtime `GuideOverlay`。
  - 題目と終わる操作: 召喚・配置・向き（最初の戦闘の開始の演出の後。1体置くまで、召喚できる最初の札→マス→近くの道の出口側を指す手）→ スロット（レバー→リール窓、リールが止まるまで）→ スキル（初めてゲージが満タンで発動できるとき。ゲージを指し、発動まで）→ 強化（初めて強化できるとき）→ 撤退（2つ目の戦闘マスで味方がいて操作がないとき。全額返還。撤退するか、レバーか次の召喚で終わる）→ 足止め（地上の敵が初めて地上の味方に止められたとき。止めている味方と敵、職ごとの道のアニメで、止められる数だけ止まり、残り1体が通り抜けて本拠地が赤く光る。押すと閉じる）→ ルート（初めてルート画面に戻ったとき。マスのアイコンごとの中身の絵（凡例）を押すか × で閉じた後、回っている行き先のあるリールを指す。どの行き先も押せる）。足止めとルートの絵は `GuidePictures` が実行時に作る（17.10・18.5）。足止めは `DemoLane` のループ（約2.5〜3.5秒、仮）。
  - 示した操作ができなくなったら（コイン不足など）終えずに引っ込め、また条件がそろえば出す。一時停止中は隠す。リール回転中は次の題目を待つ。ショップ・回復の画面中は新しい題目を出さない。ショップの絵による説明（矢印のアニメ）は `ShopScreen` と `Ui/NudgeArrow`: 押せる札は値段→品の上向きの矢印、押せる両替は払う側→受け取る側の矢印が実時間で行き来し、押せないものは止まる（売り切れは矢印を消す）。幅・速さは Claude の仮置き。
- 一時停止中の早見表（T404・T351、`HelpScreen`）: 「?」で開き ◀ で閉じる。リール・人のタブか左右の矢印で2ページを切り替える。スロットのページには 現在の設定の20パターンの内訳（図柄ごとの % ＝ 個数×5）と効果（色7 → その職の札とゲージ +1、バー → 攻撃 +10%・上限 +50%、コイン → ×1.1・上限 ×1.5）を出す。味方4種のページには 戦闘の札と同じ職の影絵とスキルの絵、右向きの範囲図、現在の強化段階の HP・攻撃（バッファーは緑の▲と倍率）・防御・攻撃間隔、ブロック数（0 は赤い ×）・コスト・待ち時間を出す。値は開くたびに読み直す。

- 発動: `Battlefield.ActivateSkill(skill)` が配置中のその職全員に効果時間を付ける（戦闘ステップで減る、一時停止・説明中は減らない）。`BattleNodeRun.TryActivateSkill(color)` は満タン・配置1体以上・戦闘中（準備中も可）を確かめ、拒否なら何も変えない（AC-023）。効果中に置いた同職の個体には付けない（発動時にいた全員だけ）。

### 16.5 バッファー（FR-028）
- `units.csv` の `healer` を `buffer`（役割 `buff`、列 `buff_rate` 1.3 を足す。費用 18・待ち時間 25 は旧ヒーラーのまま）。範囲は前方 4×3（旧ヒーラーの範囲を引き継ぐ）。範囲内の味方（自分以外）の攻撃力に、効いているバッファーのうち最大の倍率を1つだけ掛ける（重ねがけしない）。2026-11-01 に消した `buff` 処理（T206 の実装、git 履歴にある）を参考に戻す。バッファーは攻撃しない。強化は HP・防御に効き、倍率は強化しない。

### 16.6 戦闘マス（FR-010, FR-013, FR-015, FR-016, FR-018）
- `encounters.csv`（`id, kind〔first/battle/elite/boss〕, map_id, min_floor, max_floor, fixed_spins, reward_money, reward_coins`）。戦闘マスに入ったとき、種類と階が合う行から一様に選ぶ。最初のマスは `first`、強敵・ボスは専用マップ。`waves.csv` は `encounter_id, wave(1〜2), time, enemy_id, spawn, path_id, is_boss`（`stage` 列を置き換え）。

- `BattleNodeRun`（旧 `WaveRun`）: 準備 → W1 → 準備（配置・HP保持）→ W2（強敵・ボスは最後に中ボス・最終ボス）→ 終了。ライフは `RunState.Life` を使い、0でゲームオーバー。終了時: 配置中の味方を種類ごとにストックへ、報酬を加算、`BattleBoosts` は捨てる。ボスマスの終了でクリア。準備中の待ち時間なしとストックからの配置は従来どおり。

- カメラ（D-71）: Core `BattleCameraFit`（マップの列数・行数、俯角 55°、縦の画角 45°、戦闘領域の縦横比 1440:1152 から、マップ全体が収まる距離と注視点を計算）。`BattleFieldView` が戦闘マスごとに当てる。EditMode でマップの四隅が視野に入ることを確かめる（AC-014）。

### 16.7 ルート（FR-010, FR-017）
- `route_rules.csv`（キーと値: `floors`〔8〕・`columns`〔7。T358 で 4 から変更〕・`paths`〔4〕・`weight_battle`〔50〕・`weight_elite`〔14〕・`weight_shop`〔22。【2026-11-15 D-75】両替所を廃止し、その重み 10 をショップに足した〕・`weight_rest`〔14〕・`elite_min_floor`〔3〕・`rest_heal`〔3〕・`shop_slots`〔3〕・`exchange_money_per_coin`〔2〕）。
- 生成（Slay the Spire 式）: 1階は `first` の1マス、最上階はボスの1マス、その直前の階は全部回復。間の階は、`paths` 本の道を1階から列を ±1 ずつ動かしながら上へ引き（交差しない。【2026-11-15 D-75】2階の始まりも1階の列 ±1 に限り、どのマスからも上の階へ最大3方向にする）、通ったマスを残す。各マスの種類は重みで選ぶ（`elite_min_floor` 未満は強敵なし、同じ道でショップ・回復が続かない）。同じシードで同じルート（AC-010）。 T358: 横に広がるよう、道の次の列は斜めを重み2・まっすぐを重み1で選ぶ。構造を決めた後、間の階のマスに表示のずれ（横 ±0.2 列・縦 ±0.2 階、`RouteNode.DisplayOffsetX/Y`）を同じ乱数から引き、ルート画面はマスをその分ずらして置く（ずれは小さいので、まっすぐと斜めのつながりは見分けがつく）。
- マスの種類は文字列 id（`battle` など）で持ち、Core `RouteNodeKinds` の登録表と Runtime の画面の登録表（id → 画面）を足せば増やせる（D-69）。検証器は `route_rules` と登録表の食い違いをエラーにする。
- `RouteMap.CanMove(from, to)`、`RunState.Enter(node)` で現在地を進める。選べるのは今のマスにつながった上の階のマスだけ。
- 画面（【2026-11-15 D-75】）: 戦闘以外は2Dの UI。ルートは上6割の2Dオーバーレイ（戦闘フィールドを隠す）に Slay the Spire 風のマップ（下から上へ階、マスは種類のアイコン、つながりは線、今のマスと行き先が光る。8階が1画面に収まらなければ縦スクロールして今の階を見せる）、上端にライフ・所持金・コイン・ゲージ。下4割は戦闘と同じ筐体をルート選びの状態で使う。
- リールで選ぶ（D-75）: 行き先の各マスを、今のマスとの列の差の符号（−→左、0→中、＋→右）でリールに割り当てる（ボスは1つだけなのでどの差でもぶつからない）。各リールの上に矢印と行き先のアイコン、行き先のないリールは暗くする。レバー（クリックか Space）でコインを使わずに回し（回数固定も減らない）、リールは自動で止まらない。行き先のあるリール（またはその矢印）をクリックするとそのリールが止まり、残りもその場で止まって、そのマスへ `RunState.Enter`。図柄の効果は適用しない。`SlotCabinet` にルート選びのモード（`BeginRouteChoice(directions)` → 止めたリールの番号を返すイベント）を足し、Core の `SlotMachine` は通さない（コイン・出目を使わないため）。止まる位置は見た目だけの乱数。
- ショップ（両替を含む）・回復も2Dの全画面オーバーレイで、◀ でルートに戻る（回復は入った時点で回復して ◀ だけ）。ショップの両替は所持金→コイン・コイン→所持金のボタン（`Exchange`、掛け金単位）。戦闘マスでは戦闘フィールドと筐体（通常のモード）を出し、終わったらルートに戻る。

### 16.8 画面と流れ（FR-005）
- シーンは `Title` と `Game` のまま。Game に `RunController`（`RunState` を作り、ルート → 各マス → ルート を回す。戦闘は `BattleController` に `BattleNodeRun` を渡す）。リザルトは到達した階・所持金・コインを出す（クリアは王冠）。リトライは Game の再読み込みでルートも作り直す。
- 筐体（下部40%）: リール窓（3×3）、レバー、コインの数、回数固定の残り回数（コインの代わりに表示）。ストップボタン・ボーナスランプ・払い出しは消す。
- 操作バー: 味方4種のアイコン（コストは所持金のアイコンに）、各アイコンにその色のゲージ（5つの点）、満タンで光りクリックで発動（アイコン本体のクリックは召喚の選択のまま。ゲージ部分を別ボタンにする）、ライフ、所持金、ウェーブ n/2、バーの倍率（攻撃力の印に `×1.3` など）、コインの倍率（所持金の印に `×1.2`）、一時停止。旧 攻撃力・攻撃速度アップの残り秒数は消す。

### 16.9 文字あり版（FR-006, D-74）

- 【2026-11-15 D-76 で変更】「既存の部品の配置は変えず、ラベルを足すだけ」は文字なし版にだけ当てはまる。文字あり版の作り直しは 16.13。

### 16.13 文字あり版の作り直し（FR-006, AC-005, D-76、T359）
- 方式: 部品（ボタン・アイコン・数字・リール）は1組のまま両方の版で使い、文字あり版では**配置と見た目だけを差し替える**。画面ごとに別の UI を作らない（操作・テスト・画面の流れを1つに保ち、操作が両方の版で同じことを作りで守る）。
  - `TextModeLayout`（Runtime/Ui、新規）: 部品1つに付け、文字あり版の RectTransform（アンカー・オフセット・ピボット）・大きさ・TMP の字の大きさ・色・表示の有無を持つ。文字なし版の値は起動時にシーンの値を覚え、切り替えで差し替える。戻すと覚えた値を正確に書き戻す（シーンの値は書き換えない）。
  - 文字あり版だけの説明（名前・短い説明・凡例）は今までどおり `TextModeLabel`（文字なし版では描かない）。
  - 値は Editor の `Setup/Build Text Mode Layout (T359)` がコードから置く（T352 のラベルと同じやり方。シーンの既存オブジェクトは消さない）。
- 文字の大きさ: 基準解像度 1440×1920 で**最小 36**（初期ウィンドウ 960×1280 で約 24px）、本文・ラベル 40〜48、見出し 56 以上、主な数字は文字なし版と同じかそれ以上。PlayMode テストで「文字あり版で表示中の日本語のテキストはすべて 36 以上・画面からはみ出さない・互いに重ならない（同じ親の中）」を確かめる。
- 守るもの（AC-005）: 戦闘カメラの Viewport（上 60%）と筐体（下 32%）の枠、筐体の見た目（リール窓・レバー・コインの数）は文字あり版でも動かさない。操作の当たり（ボタン）は大きさを変えてよいが、同じ操作で同じことが起こる。
- 画面ごとの方針（Claude の仮置き、T355 でユーザーに見てもらう）:
  - 戦闘の HUD: 操作バー（32〜40%）は味方4種の札に絞り、札ごとに「職名・コスト・ストック・強化段階・スキルゲージ」を名前付きで出す。ライフ・所持金・コイン・ウェーブ・バーとコインの倍率・一時停止・▶ は戦闘フィールドの上端（地図の上の空き）に重ねる帯へ移し、「ライフ 10」のように名前を付ける。説明の文（`guide_*`）は画面の帯に大きく出す。【2026-11-15 T359b で実装】札は上の段にアイコンと強化、下の段に職名（説明の文がアイコンのすぐ上に出るため）。コスト・ストック・スキルゲージの名前は札に入らないので付けていない。帯のボタンは戦闘カメラの範囲に重なるので、ボタンの上のクリックはフィールドのクリックとして扱わない（`UnitPlacementInput`）。
  - 筐体: 見た目は変えず、レバー・コイン・回数固定の名前を筐体の外側の余白に大きめに出す。【2026-11-15 T359c で実装】字は 40。レバーとコインはリール窓の左右の余白（幅 約 300px）に2行、回数固定はアイコンの下。
  - ルート: 上の帯に名前付きの数字、地図の右か下にマスの種類の凡例（アイコン・名前・短い説明）、行き先の3つは「方向・マスの名前・短い説明」の札にする。【2026-11-15 T359d で実装】凡例は地図の右（地図は左に寄せて狭くなる）。札はリールの幅に収め（約 268 px）、説明は7字以内の1行（Noto Sans JP は行が高く2行では凡例に入らない）。マップは枠の大きさが変わると作り直す。
  - ショップ・回復・リザルト: 札に品の名前と短い説明、両替は「所持金 6 → コイン 3」のように文で出す。回復は回復量を文で、リザルトは「到達した階」などの名前を付ける。【2026-11-15 T359e で実装】札は上に「職名・品の名前・短い説明」の3行（札の中の絵は実行時に作るので ShopScreen が文字あり版の位置を付ける）。両替と回復量の文は数字を開くたびに入れる（`TextModeLabel.SetFormat`）。もどるは ◀ の右。
  - 早見表: 図柄の表と味方の表に見出しと列の名前、スキルと職業の短い説明。
  - タイトル・難易度選択: 難易度選択の札に「設定1（やさしい）」などの名前（タイトルは今のまま）。【2026-11-15 T359e で実装】名前は札の下（札を下げて段の間を広げる）。名前は やさしい・ふつう・やや難しい・難しい・とても難しい・最難関（仮）。タイトルは「スタート」の字だけ 40 に。
- テスト: 既存の `TextModeTests`（AC-005）を「両方の版での主な操作」まで広げる。文字なし版の見た目が変わらないことは、作り直し前に撮った文字なし版の Editor 画像（`t359-before-*-notext.png`）と作り直し後の画像の比較、と `TextModeLayout` の書き戻しの PlayMode テスト（切り替えて戻すと全部品の RectTransform・色・字の大きさが元と同じ）で確かめる。
- リスク: 部品の大きさを変えると、子の配置（アイコン内の数字など）が崩れる → 札ごとに子にも `TextModeLayout` を付け、Editor 画像で全画面を確かめる。静的フォントに無い字 → 文言を足したら `Create Text Mode Font (T352)` を先に作り直す（ハーネスか EditMode テストで、`ui_texts.csv` の全字がフォントにあることを確かめる）。

### 16.10 説明と早見表（FR-004, FR-012）
- 題目: 召喚・配置・向き（最初の戦闘）→ スロット（レバーを指す。リールが止まるまで）→ スキル（初めてゲージが満タンになったとき。光るゲージを指す）→ 強化 → 撤退（全額返還は従来どおり）→ ルート（初めてルート画面に戻ったとき。行き先のあるリールを指す）。ショップ（両替を含む）は画面自体の絵で伝える（矢印のアニメ）。`ReelCustom`・`Bonus` は消す。

### 16.11 テストと順序
- 順序: お金とライフ（Core）→ スロット（Core）→ 出目の効果・バッファー・スキル（Core）→ 戦闘マス（Core）→ ルート（Core）→ データ（マップ・出現・検証）→ 筐体 → 操作バー → 流れ（ルート・各マスの画面）→ 説明・早見表 → 文字あり版 → 文字チェックとマウス通し → 掃除と文書。各タスクで消す機能のテストは機能と一緒に消し、EditMode/PlayMode の件数の増減を tasks.md に書く。
- 途中は Game シーンが動かない期間ができる（Core を替えてから Runtime を替えるまで）。PlayMode テストのうち動かなくなるものは、そのタスクの結果に「一時的に失敗」と件数を書き、筐体・流れのタスクで直すか書き直す。Core のタスクは EditMode が全件通ることを完了条件にする。
- PlayMode の既存の知見（`SlotCabinet.RandomOverride`・`GuideOverlay.DisabledForTests`・実時間待ち・実機デバイスを止める）は新しいテストでも使う。`AlwaysMissRandom` は20パターンの「ハズレ」を選ぶ乱数に直す。

## 17. 2026-11-16 仕様変更の移行方針（M3V、spec D-77〜D-91）

### 17.1 お金を円に・2枚賭け・回す回数（FR-007, FR-040, FR-017, D-77, D-86）
- 円の桁: 所持金に関わる値（`units.csv` cost、`unit_upgrades.csv` の費用、`game_config.csv` initial_money、`encounters.csv` reward_money、`enemies.csv` の所持金ドロップ量、`shop_items.csv` price）をおよそ8倍して切りのよい数に直す。目安: 剣士 100・弓 120・タンク 130・バッファー 150、初期 250 円、戦闘の報酬 80・強敵 200、ショップの品 120〜160 円。撤退の返還は率なのでそのまま。
- `game_config.csv` bet 3 → 2、`route_rules.csv` exchange_money_per_coin 2 → 10。両替のボタンは今までどおり掛け金単位（20 円 ⇔ 2 コイン）。

### 17.11 テストと順序・リスク

| リスク | 対策 |
| --- | --- |
| 準備フェーズの廃止で説明（`GuideSequence`）と多くの PlayMode テストが壊れる | 戦闘マスの Core を先に直し、`GuideTests`・`StageTransitionTests`・`InputOnlyRunTests` などを同じタスクで書き直す |

### 18.8 テストと順序・リスク
- 順序: 倍速とスロー → 重装と弓（Core、TDD）→ マップ（データ・検証器）→ 戦闘画面の UI の試作（撮影をユーザーが確認）→ 戦闘画面の UI（帯・札・詳細・バー・印）→ 文字なしの説明 → ルートの線 → ほかの画面の UI → 演出 → 文字あり版の追従 → 掃除と文書 → 通しプレイ。
| リスク | 対策 |
| --- | --- |
| UI を全部作り直すと PlayMode テストの参照（ボタンや帯の場所）が多く壊れる | 部品の名前・コンポーネントは残して配置と見た目を替える。壊れたテストは同じタスクで直し、件数を tasks.md に書く |
| 見た目の好みが合わずにやり直しが増える | 戦闘画面の試作で一度ユーザーに確かめてから広げる |
| 配置中のスローと一時停止・説明・倍速が `Time.timeScale` で食い違う | 決まりは `ApplyTimeScale` の1か所で、PlayMode で組み合わせ（配置中に一時停止、配置をやめる、倍速3）を確かめる |
| 弓を弱めすぎて空中の敵に勝てない | 空中の敵の体力も同じシミュレーションで確かめ、空中だけの群れは弓2体で倒せる値にする |
| 新マップでカメラに入りきらない | 9〜10×4〜5 の大きさを守り、`Camera_Fits_Every_Map` と撮影で確かめる |

## 19. 2026-11-20 仕様変更の方針（M3X、spec D-101〜D-108）
要求は spec の FR-078〜FR-085・AC-059〜AC-066 を参照する。数値・見た目はすべて Claude の仮置きで、絵は見た目の方向が決まってから差し替える（T502）。元の指摘は [playtest-t399.md](playtest-t399.md)。

### 19.1 データ（FR-084, FR-085, D-107, D-108）
- `game_config.csv` の `placement_time_scale` を 0.2 に。AC-055 の PlayMode テストは期待値を設定から読むか 0.2 に直す。
- `encounters.csv` に `weight`（既定 1、0 より大きい）を足し、`EncounterTable.Pick` を重み付きの選び方にする（Core を TDD、`avoidMapId` の除外は今までどおり先に行う）。一本道の battle_a〜c を 7、battle_d・e を 26 にして約 35％（直前と同じマップを避ける決まりで一本道が増えるため、20 だと約 39％になった。T420）。検証器は weight ≤ 0 をエラーにする。AC-065 は固定シードで 10,000 回、通常の戦闘マスで一本道の割合が 30〜40％（直前と同じマップを避ける決まりも入れたまま）。

### 19.2 本拠地に入られたときの赤い光（FR-078, D-101）
- 画面いっぱいの Overlay Canvas に縁だけ赤い `Image`（中央が透明のグラデーションのスプライトを実行時に作る）を置き、`Battlefield.BaseReached` で不透明度 0.55 → 0 を 0.45 秒（`unscaledDeltaTime` ではなく通常の時間、一時停止中は止まる）。クリックは通す（`raycastTarget` false）。連続で入ったら最初から光り直す。既存の本拠地とライフの光（T388）はそのまま。長さは `BattlePresentationTiming` に足す。

### 19.3 敵の通り道（FR-079, D-102）
- `BattleFieldView` は経路を常時表示せず、道ごとに出し入れする（`ShowPath(id, seconds)`・`ShowAllPaths`・`HideAllPaths`）。
- 線の仮の形: 道に沿って並べた小さな矢印（シェブロン）が出口から本拠地へ流れる。地上は地面すれすれの白、空中は飛ぶ高さに水色で、真下の地面に薄い点線の影を落として、どのマスの上を飛ぶかが分かるようにする。
- 出す時: 開始の演出（`BattleIntroView`）の間はすべて。戦闘中は `Battlefield.EnemySpawned` のうち、その道で最初の出現、または直前の同じ道の出現から3秒以上空いたときでその道を 2 秒出し、0.3 秒で縮んで消える。時間は戦闘の時間で進む（配置中のスローと一時停止に従う）。

### 19.4 一時停止の「?」とタイトルへ戻る（FR-080, D-103）
- 「?」は一時停止中だけ上端の帯の中（一時停止ボタンの左）に出す。その左に「タイトルへ戻る」（家の形のアイコン）。押すと中央に確認の板（✔・×、文字あり版は「タイトルに戻りますか？」）を出し、✔ で `Time.timeScale` を 1 に戻して Title を読み込む。× で一時停止に戻る。キーボードの扱いは今の一時停止に合わせる（Esc で確認を閉じる）。
- 撮影と PlayMode テストで、帯のボタンが盤上のキャラ・空中の敵と重ならないことを確かめる（文字あり版も）。

### 19.5 早見表のページ（FR-081, D-104）
- `HelpScreen` の上半分（スロット）と下半分（味方）を別ページにし、上にアイコンのタブ（リール・人の形）、左右に矢印。今のページは `HelpScreen` が覚える（同じプレイの中だけ）。各ページは今の倍近い広さを使えるので、字と絵を大きくする。部品は `HelpPagesSetup` で作り直し、文字あり版の配置は `TextModeLayoutSetup`。読みやすさの判定（`TextReadability`）を両方のページで通す。

### 19.6 遠距離攻撃の弾（FR-082, D-105）
- `BattleActorsView` が攻撃のイベント（遠距離職と遠距離の敵の攻撃）を受けて、撃った所から相手の位置まで弾を飛ばす（直線、弓は細長い矢、敵は小さな玉）。飛ぶ時間は攻撃間隔の 1/3 と 0.2 秒の短い方。ダメージは今までどおり攻撃の瞬間に入る（弾は見た目だけ）。弾は使い回し（プール）にして毎回作らない。相手が先に消えたら最後の位置まで飛んで消える。
- Core の `Battlefield.UnitAttacked`・`EnemyAttacked` はダメージの後で通知する。

### 19.7 説明の進め方（FR-083, D-106）
- どの対象でも進む: 説明の暗い幕はクリックを止めない。光る枠と手はおすすめを示すだけにする。`GuideSequence` の終わりの条件は「示した対象」ではなく「その種類の操作をした」（召喚した・置いた・向きを決めた・どれかのスキルを使った・どれかを強化した・どれかを撤退した・どれかの行き先を選んだ）で判定する（Core を TDD）。
- 閉じられる: 光る枠の右上の外に ×。押すと `GuideObservation.Dismissed` で、題目を終了する。ルートの凡例では選び方へ進む。撤退の題目の全額返還（D-56）は「題目が出ている間」のまま。
- ルートの説明: `RouteNodes`（凡例）を出している間は `RoutePick` の手とリールの光を出さない。凡例を押すか × で閉じてから `RoutePick` に進む。
- 向き選び: 手の向きは、置いたマスから3マス以内で一番近い道のマスを探し、その道でそのマスより出口側の隣のマスの方向（4方向に丸める）。道が近くにないときは今までどおり。

### 19.8 確かめ方
- EditMode: 重み付きの選び方と割合（AC-065）、説明の終わりの条件・閉じる（AC-064 のロジック）、攻撃のイベント（あれば）。
- PlayMode: 赤い光（AC-059）、道の出し入れ（AC-060）、確認を挟んでタイトルへ（AC-061）、早見表のページ（AC-062）、弾（AC-063）、説明中にほかの札で置いても進む・× で進む・凡例と選び方が同時に出ない（AC-064）、スロー 1/5（AC-066）。
- 撮影: 文字なし・文字あり版の戦闘（赤い光・道の線・帯のボタン・弾）、早見表の2ページ、確認の板。最後にユーザーの通しプレイ（道の線と説明の分かりやすさ）。

### 19.9 リスク
| リスク | 対策 |
|---|---|
