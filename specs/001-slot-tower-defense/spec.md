## 目的
スロットで資金と戦闘の強化効果を得て、4種類の味方を召喚・アップグレードし、敵の特徴に合わせてグリッド上の配置を工夫しながら、3ステージ（各2ウェーブ）の防衛を目指す戦略型タワーディフェンス。戦闘部分はアークナイツに準じる。

面白さの柱: スロットで揃えた効果が戦況を変える爽快感 / 自分で組むリールの戦略性 / 召喚する味方を選ぶ戦略性 / アップグレードによる育成 / グリッド配置の工夫 / 敵に応じた戦い方の変化 / 死亡で完全消滅する緊張感 / 3ステージ突破の達成感。

### 全体・画面・操作
- D-01 ジャンルはスロット × タワーディフェンス。戦闘・配置・攻撃範囲・クリア/ゲームオーバーの考え方はアークナイツ準拠。
- D-12 対象プラットフォームはPC。
- D-15 画面は実際のスロット筐体をモチーフにした縦長レイアウト（PCでも縦長）。
- D-11 【2026-11-01 変更】画面の上部約6割が戦闘フィールド、下部約4割がスロット。両者を1画面に同時表示する。（旧: 上部3〜4割が戦闘）
- D-39 戦闘フィールドは斜め見下ろしの3D（アークナイツ風）。
- D-16 操作はマウスだけで完結でき、キーボードでも同じ操作ができる。
- D-37 【制作上の制約】UIで文字は一切使用しない（言語の壁をなくすため）。アイコン・画像・色・演出で意味が伝わるようにする。数字は使用可。例外としてタイトル画面のみ文字（ゲーム名ロゴ等）を使える。説明は画面を薄暗くして矢印・数字・アイコンで示し、必要な場所では絵やアニメーションで見せる。

- D-38 難易度は設定1〜6の6段階。
- D-32 ゲームの数値（キャラ・敵ステータス、召喚・強化費用、待ち時間、配置上限、撤退返還率、ライフ、ドロップ、スロットのハズレ率・図柄効果・払い出し・リールのマス数、難易度ごとの値など）はすべてデータテーブルで調整できる。初期値は実装計画で仮置きし、プレイで調整する。

### 進行・勝敗
- D-03 【2026-11-01 変更】3ステージ制で、各ステージは2ウェーブ（合計6ウェーブ）。ステージ1・2の最終ウェーブの最後に中ボス、ステージ3の最終ウェーブの最後に最終ボス。最終ボス撃破でクリア。（旧: 全5ウェーブ）
- D-13 戦闘はリアルタイムで進行し、スロット操作中も止まらない。
- D-17 一時停止を備える。倍速はなし。一時停止中はキャラクター詳細やスロットの説明を見られるが、配置・撤退・強化・スロットなどの操作はできない。
- D-18 【2026-11-01 変更】敗北条件はライフ制（敵がゴールに到達するとライフが減り、0でゲームオーバー）。ライフはステージごとに満タンに戻り、ステージクリア時に残りライフの数に応じたコインを得る。（旧: ウェーブごと）
- D-19 【2026-11-01 変更】ステージごとに別マップ。同じステージ内の2ウェーブは同じマップで、配置もそのまま続く。各ステージ開始時に配置をやり直す。（旧: ウェーブごとに別マップ）
- D-04 【2026-11-01 変更】ステージ間で引き継ぐのは、キャラクター（D-24 の無料ストック）・アップグレード状態・所持コイン・リール配列。配置とHPは引き継がない。
- D-24 【2026-11-01 変更】ステージ終了時に配置していた味方は、種類ごとに同数の「無料ストック」になり、次のステージのマップでコインなしで配置できる。
- D-27 無料ストックからの配置は完全な新規配置として扱う（HPは全快、前ステージの状態を持ち越さない）。

### 味方・召喚・強化
- D-05 【2026-11-01 変更】味方は4種類: タンク（近距離、複数体ブロック）、近距離アタッカー（剣士）、遠距離アタッカー（弓）、ヒーラー。同種を複数体同時に召喚できる。バッファーは廃止。
- D-02 初期支給コインで召喚を始める。
- D-06 / D-20 召喚はプレイヤーが種類を指定して行い、費用はコインのみ。同時配置数に上限がある。
- D-41 召喚の待ち時間は種類ごと（ある種類を召喚しても、他の種類は待たずに召喚できる）。
- D-07 HPが0になった味方は消滅する。
- D-21 / D-23 配置変更は撤退して再配置する方式。撤退した味方は消え、召喚コインの一部が返還される。
- D-22 アップグレードは種類ごと。同種の配置中・今後召喚する全個体に効く。
- D-42 アップグレードは戦闘中いつでもコインを払って行える（一時停止中を除く: D-17）。
- D-28 【2026-11-01 変更】ヒーラーは攻撃範囲内でHP割合が最も低い味方1体を回復する。（バッファーの記述を削除）

### マップ・配置・戦闘
- D-09 マップはグリッド。役職ごとに配置可能マスが決まる。
- D-25 【2026-11-01 変更】配置マスと向きはアークナイツ準拠: 近距離職（タンク・剣士）は地上マス、遠距離職（弓・ヒーラー）は高台マス。配置時に向きを選び、攻撃範囲は向きに従う。
- D-26 【2026-11-01 変更】空中の敵は遠距離アタッカー（弓）だけが攻撃でき、ブロックできない。ブロック数はタンクが複数体（初期値の目安3）、剣士が1〜2、弓・ヒーラーは0。
- D-08 敵: 通常3種（地上の近距離雑魚・地上の遠距離雑魚・空中雑魚）＋ボス2種（中ボス・最終ボス）。
- D-34 遠距離雑魚敵は射程内なら高台の味方も攻撃する。

### コイン・スロット
- D-29 主な収入源はスロット。敵撃破のコインはスロットを回す資金程度の補助。
- D-30 敵は撃破時に確率でコインを落とし、確率と量は敵の種類ごとに異なる。
- D-14 【2026-11-01 変更】スロットはリール3本を1本ずつボタンで止める。1回の掛け金は固定。目押しは停止操作の演出として残し、結果には影響しない（D-44）。
- D-10 【2026-11-01 変更】図柄（役）は「攻撃力アップ・攻撃速度アップ・全体HP回復・コイン・7・BAR」の6種類。同じ図柄が3つ揃うと成立。（旧: ベル・リプレイ・チェリー・スイカ・7とレア役）
- D-33 / D-40 【2026-11-01 変更】ボーナスは BIG（7・7・7）と REG（BAR・BAR・BAR）の2種類。REG は BIG より小さい。払い出しはボーナス中のゲームを消化しながら増えていく方式。（旧: REG は 7・7・BAR）
- D-31 【2026-11-01 変更】確変と先バレは廃止。
- D-43 当たり方: 毎回まず難易度ごとの確率でハズレかどうかを抽選する。当たりのときは、リール配列での各図柄のマス数の比率がそのまま「揃う図柄」の確率になる。何も揃わない（ハズレ）こともある。
- D-44 目押しは結果（当たり/ハズレ・揃う図柄）を変えない。
- D-45 図柄の効果（数値はデータテーブル、括弧内は初期値の目安）:
  - 攻撃力アップ: 配置中の味方全員の攻撃力を一定時間上げる（1.5倍・20秒）。効果中に再度揃えると時間を延長。
  - 攻撃速度アップ: 配置中の味方全員の攻撃間隔を一定時間短くする（1.5倍速・20秒）。再度揃えると延長。
  - 全体HP回復: 配置中の味方全員のHPを最大HPの一定割合だけ即時回復（50%）。
  - コイン: コインを払い出す。
  - 7 / BAR: BIG / REG（D-33 / D-40）。
- D-46 【2026-11-04 変更】リールはプレイヤーがカスタム画面で組む。リール1本のマス数は12（データテーブルで変更可）。6図柄（7・BAR・攻撃力アップ・攻撃速度アップ・全体HP回復・コイン）は最初から1つずつ決まった位置のマスにロックされていて、動かすことも変えることもできない（位置はデータテーブル）。残りの空きマスには、攻撃力アップ・攻撃速度アップ・全体HP回復・コインを数の制限なくドラッグ＆ドロップで入れる。空きマスが1つでも残っていると確定できない。確定するまでは、入れた図柄を別の図柄で上書きしたり外して空きに戻したりできる。ゲーム開始時の空きマスはすべて空。（旧: 全マスをクリックで図柄を切り替えて組む。7・BAR はちょうど1つ、ほかは各1つ以上）
- D-47 3本のリールは同じ配列を使う（1回組めば全リールに反映）。
- D-48 【2026-11-04 変更】カスタムできるのはゲーム開始時の1回だけ。確定した配列はそのゲームのあいだ変えられない（リトライ・タイトルから始め直すとまたカスタムする）。（旧: ゲーム開始前と各ステージの間）
- D-49 カスタム画面には、現在の難易度でのハズレ確率と当たり確率、当たり時の各図柄の確率を、数字とアイコンで表示する（文字なし）。
- D-50 （2026-11-04）カスタム画面のキーボード操作: 上下で入れる図柄（4種）を選び、左右でマスを移る（ロックされたマスは飛ばす）。Space で選んだマスに入れる（入っていれば上書き）、Backspace か Delete で外す、Enter で確定する。
- D-51 （2026-11-04）カスタムの説明（文字なし）は、手のアイコンが図柄を空きマスへドラッグして入れるアニメーションで示す。（ユーザー指摘: 最初の説明が分かりにくい）
- D-52 （2026-11-04）有効ラインは上段・中段・下段の横3本。（旧: 中段の1本。上段・下段で揃っても払い出しがなく分かりにくい、というユーザー指摘による）
- D-53 （2026-11-04）当たり・ハズレの抽選（D-43）は変えない。当たりは1ゲームに1つで、揃う図柄を上・中・下のどれか1段にだけ揃え、ほかの段は揃えない。ハズレのときはどの段も揃わない。確率と払い出しのバランスは変わらない。

### 味方

- FR-026 アップグレードは種類ごとに段階的に行え、戦闘中いつでもコインで実行できる。効果は配置中と今後召喚する同種の全個体に及ぶ。（D-22, D-42）
- FR-027 ブロック: タンクは複数体、近距離アタッカーは1〜2体の地上敵を足止めする。遠距離アタッカーとヒーラーはブロックしない。（D-26）
- FR-028 ヒーラーは攻撃範囲内でHP割合が最も低い味方1体を回復する。（D-28）

### 敵
- FR-030 敵は地上の近距離雑魚・地上の遠距離雑魚・空中雑魚・中ボス・最終ボスの5種類。（D-08）
- FR-031 空中雑魚はブロックされず、遠距離アタッカーだけが攻撃できる。（D-26）
- FR-032 遠距離雑魚は射程内の味方（高台を含む）を攻撃する。（D-34）
- FR-033 敵は撃破時に、種類ごとの確率と量でコインを落とす。（D-30）

### スロット
- FR-040 固定の掛け金でベットし、レバーで回転し、3本のリールを1本ずつボタンで止める。所持コインが掛け金未満なら回せない。止めるタイミングは結果に影響しない。（D-14, D-44）
- FR-041 【2026-11-04 変更】毎回、難易度ごとのハズレ確率で当たり/ハズレを決め、当たりのときはリール配列の図柄比率（マス数÷総マス数）の確率で揃う図柄が決まる。有効ラインは上段・中段・下段の3本で、当たりは揃う図柄がどれか1段にだけ揃い、ハズレはどの段も揃わない。停止後の出目は決まった結果と矛盾しない。（D-10, D-43, D-52, D-53）
- FR-042 攻撃力アップ・攻撃速度アップは、配置中の味方全員に一定時間効果を与え、効果中に再度揃えると時間が延長される。全体HP回復は配置中の味方全員を最大HPの一定割合だけ即時回復する。コインはコインを払い出す。（D-45）
- FR-043 7・7・7 で BIG、BAR・BAR・BAR で REG のボーナス状態になり、ボーナス中のゲームを消化しながら払い出しが増えていく。REG は BIG より払い出しが小さい。（D-33, D-40）
