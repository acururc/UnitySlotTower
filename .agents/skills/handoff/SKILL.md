# 引き継ぎの更新と再開

## 更新
`docs/ai/HANDOFF.md` の「現在の作業」節を古い内容ごと置き換える（追記しない、通常600語以内）。

- 目的・完了条件 / 対象spec（パス）と段階
- ユーザーの確定条件・承認とその範囲（拡大解釈しない）
- 完了した作業と変更ファイル、実際に実行した検証と結果（未実行は明示）
- 不明な結果・ブロッカー、Unity接続状態、次に実行する具体的な操作（必要なら正確なコマンド）

詳細ログや会話の転記、秘密情報は入れない。仕様の内容はspecへのリンクで済ませる。

## 再開
HANDOFFの「現在の作業」節だけを読み、記載されたspec・ソース・Git状態・テスト結果と照合してから次の操作に進む。保存された状態は新しい承認ではない。
