# 軽量仕様ワークフロー

手順と雛形の正本は `docs/ai/SPEC_WORKFLOW.md`。初回はそれを読む。

1. `specs/` の既存番号を確認し、対象機能を特定する（新規なら `specs/NNN-short-name/`）。再開時は `docs/ai/HANDOFF.md` の現在状態と対象 `spec.md` を照合する。
2. `spec.md` を作成・更新する。重要な未決事項は推測で埋めず、結果を左右する質問を1つずつ聞き、回答をすぐ `spec.md` に反映する。
3. 重要な未決事項がなくなったら、保存済みの現行 `spec.md` と検証方法を提示し、ユーザーの明示的な承認を得る。承認は `spec.md` の「承認」欄に日付と承認範囲で記録する。依頼文や過去回答から承認を推測しない。spec変更後は承認をやり直す。
4. 承認後に `plan.md`（設計・影響ファイル・リスク）と `tasks.md`（検証可能な小タスク）を作り、実装する。
5. 各タスク完了ごとに `unity-verify` の手順で確認し、`tasks.md` にチェックと実際の検証結果を残す。中断・段階移行時は HANDOFF を更新する。
